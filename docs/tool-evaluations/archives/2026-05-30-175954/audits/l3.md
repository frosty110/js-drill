## Strengths
- **Per-attempt history is the richest data lane in the app** (`12c-l3.js:74, 447, 519, 573`) — `L3-enter`, `hint-tier-N`, `critical-lines-used`, `L3-pass` events power Pace-Bar (`12c-l3.js:140-148`), hint-frequency trend (`12c-l3.js:401-431`), per-attempt hint-cost ribbon (`12c-l3.js:416-427`), and Streak Map. No other tool ships this telemetry density.
- **Mock Interview is the only tool that strips ALL scaffolds** (`12c-l3.js:162-200`) — Hint, Critical lines, Edge chips, L3 chips, debug button ALL hidden via `isMock` gates. The transfer-context match is maximal precisely BECAUSE the affordances disappear.
- **Hint ladder is tiered, tracked, and graphed** (`12c-l3.js:37-46, 437-457, 401-431`) — Approach → Skeleton → First step; each tap appends `hint-tier-N` to history; trend pill shows "scaffold used on N of last K attempts" with color band. A user can WATCH their hint-dependency trend down across SR intervals.

## Weaknesses
- **Block-practiced at lesson grain** (`12c-l3.js:48`) — same blocked-practice limitation as L1/L2. The Mock Interview "random pick" feature (referenced at `12c-l3.js:606-609`) partially interleaves, but only across mocks, not within a study session of L3 drills.
- **L3 is high-friction on phone** (PROFILE.md:34-36, acknowledged by design) — the `L3-chip` keyboard helpers (`12c-l3.js:185-189`) mitigate but don't eliminate the typing barrier. The Notes→Code Reference-tab variant (`11-tabs-ref-conv-walk.js:763-816`) is a parallel surface for the same recall direction.
- **Pace-Bar requires median calibration** (`12c-l3.js:86, 149`) — auto-hides when there's no history. First-time L3 attempts get no tempo signal; the user has to grind a few attempts to earn the cue.
