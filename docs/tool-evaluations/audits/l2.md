## Strengths
- **Per-blank tiered reveal is the new default** (`12b-l2.js:119-145` desktop, `:565-585` mobile) — the "?" button on each input/sheet surrenders only that blank, preserves production on the rest, and demotes SR exactly once per exercise via the `anyRevealed` guard. Crosses the Bjork "desirable difficulty" threshold for L2: the user must intentionally surrender each blank rather than wave a single white flag.
- **Mobile-first variant ships its own UX** (`12b-l2.js:279-621`) — tap-chip + shared bottom sheet honors PROFILE.md:31-33 ("L2 is feasible on mobile — short token typing"). Cache shape mirrors desktop so viewport-switching mid-attempt is symmetric (`:283-322` with getter/setter pass-through to cache so writes auto-sync).
- **Struggle-pass weakness signal** (`12b-l2.js:158, 188-191, 390, 416-419`) — three-attempts-then-pass writes `state.weakness` + history. The SR loop can now distinguish a clean pass from a fought-out pass without requiring full reveal.

## Weaknesses
- **Block-practiced at lesson grain** (`12b-l2.js:63`) — same as L1 base, no cross-lesson card mixing inside the L2 tab.
- **No per-blank conceptual feedback** (`12b-l2.js:208`) — when a specific blank stays wrong across attempts, the user gets red/green outline but no "you wrote X because you confused Y with Z" diagnostic. Per-blank `whyAnswer` schema would close this.
- **Bulk "Reveal answers" still exists alongside per-blank** (`12b-l2.js:211-230, 437-460`) — one tap can still erase all production. The button is amber-styled as the secondary action now and demotes SR only when first invoked, but a hurried user can still bypass recall entirely.

## Salvage path (if IMPROVE — but verdict is KEEP at 18/21)

L2 crossed the KEEP ship-quality band at 18/21 with the Phase 5-promote per-blank reveal. Remaining headroom is Feedback quality (2→3) and Interleaving (1→2). Defensible single edits:

1. **Authored per-blank `whyAnswer` (validator-soft)** — `12b-l2.js:208` — extend schema `blanks: [{answer, hint?, whyAnswer?}]`; on a wrong-blank check, surface `whyAnswer` next to the red outline. Lifts **Feedback quality** by +1 (2→3: per-blank conceptual diagnostic). Authoring cost is real; engine ships first.
2. **One cross-lesson L2 carry-over exercise per session** — mirror L1's `_pickCarryoverL1Question` pattern — pick ONE random weak-spot lesson's first L2 exercise, render as a leading carry-over card, exclude from `checkL2Overall`. Lifts **Interleaving** by +1 (1→2). Reuses the carry-over pattern shipped on L1 this campaign.
