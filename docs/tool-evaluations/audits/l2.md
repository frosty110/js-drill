## Strengths
- **Mobile-first variant ships its own UX** (`12b-l2.js:226-520`) — tap-chip + shared bottom sheet honors PROFILE.md:31-33 ("L2 is feasible on mobile — short token typing"). Cache shape mirrors desktop so viewport-switching mid-attempt is symmetric (`:230-256` with getter/setter pass-through to cache so writes auto-sync).
- **Struggle-pass weakness signal** (`12b-l2.js:114, 143-147, 322, 347-351`) — three-attempts-then-pass now writes `state.weakness` + history. The SR loop can now distinguish a clean pass from a fought-out pass without requiring full reveal.
- **96px uniform input width prevents length-leak** (`12b-l2.js:93-94`) — a real production-direction discipline; longer/shorter slots would telegraph answer length.

## Weaknesses
- **Reveal answers is one-click flat** (`12b-l2.js:167-177, 369-385`) — even per-card. A "show me ONLY blank 2's answer" tier would preserve the production attempt on blanks 1, 3, 4. Current UX makes giving up easy.
- **Block-practiced at lesson grain** (`12b-l2.js:51`) — same as L1 base, no cross-lesson card mixing inside the L2 tab.
- **No per-blank conceptual feedback** (`12b-l2.js:163`) — when a specific blank stays wrong across attempts, the user gets red/green outline but no "you wrote X because you confused Y with Z" diagnostic. Per-blank `whyAnswer` schema would close this.

## Salvage path (if IMPROVE)
Ordered by leverage.

1. **Per-blank reveal (tier the reveal)** — `12b-l2.js:167-177` — replace the flat "Reveal answers" button with a per-blank "?" affordance on each `.blank-input`. Tapping the ? reveals ONLY that blank and writes a per-blank-revealed flag. Lifts **Active recall** by +1 (2→3: full per-card reveal stops being one tap; user must intentionally surrender each blank).
2. **Authored per-blank `whyAnswer` (validator-soft)** — `12b-l2.js:163` — extend schema `blanks: [{answer, hint?, whyAnswer?}]`; on a wrong-blank check, surface `whyAnswer` next to the red outline. Lifts **Feedback quality** by +1 (2→3: per-blank conceptual diagnostic). Authoring cost is real; engine ships first.
3. **One cross-lesson L2 carry-over exercise per session** — mirror L1's `_pickCarryoverL1Question` pattern — pick ONE random weak-spot lesson's first L2 exercise, render as a leading carry-over card, exclude from `checkL2Overall`. Lifts **Interleaving** by +1 (1→2). Reuses the carry-over pattern shipped on L1 this run.
