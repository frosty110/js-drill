Blackjack Hand Value

Score a Blackjack hand. J/Q/K=10, numbers as-is, Aces are 11 unless that busts — then count that ace as 1. Demotes one ace at a time until the total fits or runs out.

Problem

Implement handValue(cards). Log values for ['A','K'], ['A','9','5'], ['A','A','9'], ['10','Q','2'].

Expected output: 21 15 21 22

Canonical solution

function handValue(cards) {
  let total = 0, aces = 0;
  for (const c of cards) {
    // Count aces as 11 optimistically; demote later only if busted.
    if (c === 'A')           { total += 11; aces++; }
    // 'JQK'.includes(c) is tighter than an array for face-card test.
    else if ('JQK'.includes(c)) total += 10;
    else                        total += Number(c);
  }
  // Demote one ace at a time — ['A','A','9'] should land at 21, not 11.
  while (total > 21 && aces > 0) {
    total -= 10;
    aces--;
  }
  return total;
}
  • Count aces as 11 first, then demote one-by-one ONLY while the hand busts. Demoting all aces upfront under-scores ['A','9'] (would give 10 instead of 20).
  • 'JQK'.includes(c) is a tight way to test face cards without an array.
  • The while loop terminates either when total ≤ 21 or aces hit 0 — the bust is unavoidable.
  • Time O(n), Space O(1) where n = number of cards.

Alternate approaches

Brute-force (enumerate 2^k ace combinations) O(n · 2^k) / O(k)

Reach for this only when explaining WHY the greedy works — the exponential search space makes the greedy's invariant ('at most one soft Ace') feel non-obvious to an interviewer who hasn't seen it before. Don't write this for production; k ≤ 4 aces keeps it fast in practice but the greedy is strictly better.

function handValue(cards) {
  const aces = cards.filter(c => c === 'A').length;
  const baseTotal = cards.reduce((s, c) => {
    if (c === 'A') return s;
    if ('JQK'.includes(c)) return s + 10;
    return s + Number(c);
  }, 0);
  let best = -Infinity;
  for (let mask = 0; mask < (1 << aces); mask++) {
    let total = baseTotal;
    for (let i = 0; i < aces; i++) total += (mask >> i & 1) ? 11 : 1;
    if (total <= 21) best = Math.max(best, total);
  }
  return best === -Infinity ? baseTotal + aces : best;
}
console.log(handValue(['A','K']));
console.log(handValue(['A','9','5']));
console.log(handValue(['A','A','9']));
console.log(handValue(['10','Q','2']));
  • Compute non-ace sum first, then try all 2^k combinations of aces as 1 or 11.
  • Track 'best non-busting total'; if ALL combinations bust, fall back to the all-1s total.
  • O(n · 2^k): the inner loop is bounded by aces ≤ cards, but for a single deck k ≤ 4 so 2^k ≤ 16 — effectively constant.

Q1 What does the Ace contribute initially?

  1. A 1 always
  2. B 11 always — and is demoted to 1 only if the hand busts correct
  3. C 11 if it is the first card, else 1
  4. D 1, then is promoted to 11 at the end if total + 10 ≤ 21

Q2 Why demote aces one at a time instead of all at once?

  1. A Demoting all aces in one step would lose insertion order from the hand
  2. B Each ace is independent — ['A','A','9'] should be 21 (one ace at 11, one at 1), not 11 correct
  3. C Demoting all at once costs O(n) per call instead of O(1)
  4. D The while loop must run at least aces iterations to be valid

Q3 What is the value of ['A','K']?

  1. A 11
  2. B 20
  3. C 21 correct
  4. D 12

Q4 What is the value of ['10','Q','2']?

  1. A 12
  2. B 22 correct
  3. C 20
  4. D 10
