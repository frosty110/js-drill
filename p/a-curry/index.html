Curry

Turn `fn(a, b, c)` into a function you can call as `f(a)(b)(c)`, `f(a, b)(c)`, or `f(a, b, c)` — the recursive-args-accumulator pattern.

Problem

Implement curry(fn). Demonstrate all three call shapes on add(a,b,c) — f(1)(2)(3), f(1,2)(3), and f(1,2,3) — log each result.

Expected output: 6 6 6 6

Canonical solution

function curry(fn) {
  return function curried(...args) {
    if (args.length >= fn.length) {           // enough args — fire it
      return fn.apply(this, args);
    }
    return function (...more) {                // not enough — collect more
      return curried.apply(this, args.concat(more));
    };
  };
}
const add = (a, b, c) => a + b + c;
const c = curry(add);
c(1)(2)(3);        // 6
c(1, 2)(3);        // 6
c(1)(2, 3);        // 6
c(1, 2, 3);        // 6
  • fn.length is the count of declared parameters (before any default value) — the arity the curry compares against.
  • Recursion via the named curried callee lets each partial call append args and re-check arity.
  • Default params and rest params change fn.length semantics; rest params count as 0. For variadic functions, curry doesn't apply.
  • Time O(n²) worst-case (n one-arg calls each copy growing array via concat). Space O(n) for closure chain. n = arity, typically ≤ 5 in practice.

Implement curry(fn). Demonstrate all three call shapes on add(a,b,c) — f(1)(2)(3), f(1,2)(3), and f(1,2,3) — log each result.

Hints
  • Compare collected args.length against fn.length to decide fire-or-defer.
  • Use a named inner function so the next partial can recurse on it.
  • Concat the new args onto the closure's args — never mutate the closed-over array.
function curry(fn) {
  // Named inner fn so each partial call can recurse on itself to re-check arity.
  return function curried(...args) {
    // fn.length is declared param count — enough args means fire.
    if (args.length >= fn.length) return fn.apply(this, args);
    // concat (not push) — never mutate the captured args across sibling partials.
    return function (...more) { return curried.apply(this, args.concat(more)); };
  };
}
