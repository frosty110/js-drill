Medical Record Dedup

Hash-set on a normalized fingerprint — a single `for` pass over discovery pages, keying a Set on lowercased/whitespace-collapsed text so duplicate pages in different casing or spacing collapse to one; keep first, count the rest.

Problem

Discovery produced duplicate pages with inconsistent whitespace/casing. Dedupe by a normalized fingerprint (lowercase, collapse runs of whitespace to one space, trim). Keep the first occurrence's id; report kept ids and how many duplicates were removed.

Expected output: Kept: p1, p3 Duplicates removed: 2

Canonical solution

Hash set on a normalized text fingerprint · O(n·L) / O(n·L) (time / space)

// Discovery dumps the same page repeatedly with inconsistent casing/whitespace.
// Dedupe on a NORMALIZED fingerprint, not the raw text.
function dedupe(pages) {
  const seen = new Set();
  const kept = [];
  let dups = 0;
  for (const p of pages) {
    // Normalize: lowercase, collapse any run of whitespace to one space, trim.
    const key = p.text.toLowerCase().replace(/\s+/g, ' ').trim();
    if (seen.has(key)) { dups++; continue; }   // already seen — count, skip
    seen.add(key);
    kept.push(p.id);                            // keep the FIRST occurrence's id
  }
  return { kept, dups };
}
  • Normalize before comparing. Raw === treats 'Patient stable.' and 'patient STABLE.' as different, so the duplicate slips through. The fingerprint folds casing and whitespace away first.
  • replace(/\s+/g, ' ') collapses any run of spaces, tabs, or newlines into a single space; the trailing .trim() strips leading/trailing whitespace the collapse leaves behind.
  • Keep the FIRST occurrence: on a hit, continue past the page without overwriting seen or kept. Pushing on every miss (not every page) is what makes 'first wins' hold.
  • Time O(n·L), Space O(n·L) — one pass over n pages; each fingerprint costs O(L) to build and hash; Set holds up to n strings of avg length L.

L1 — Concept questions 4

Q1 Why normalize the text into a fingerprint before comparing pages?

  1. A Set.has hashes the input via Object.prototype.toString, which is case-sensitive, so the key must be pre-lowered
  2. B Raw equality (===) treats different casing/whitespace as distinct, so real duplicates would not be caught correct
  3. C Storing the raw text in a Set would retain reference identity, so equal-by-value strings would still miss
  4. D replace(/\s+/g, ' ') returns a value that Set accepts; the unmodified text would be coerced to [object String]

Why: 'Patient stable.' and 'patient STABLE.' are the same page; only after lowercasing and collapsing whitespace do they hash to the same key.

Q2 Why use a Set of fingerprints rather than re-scanning kept for each page?

  1. A kept.includes(key) does deep equality on objects, which would mis-match string fingerprints
  2. B Set membership (has) is O(1), so the whole dedup is O(n) instead of O(n^2) correct
  3. C Iterating kept mid-loop would mutate the index and skip pages
  4. D A Set can hold arbitrary objects as keys; arrays can only hold primitive types

Why: Scanning the kept list for every page is O(n^2). A Set gives constant-time membership, keeping the pass linear.

Q3 How does the code guarantee it keeps the FIRST occurrence of a duplicate?

  1. A Set.add returns the prior value on collision, which is used to overwrite kept[i] with the earlier id
  2. B On a Set hit it increments the count and continues without overwriting seen or kept correct
  3. C It checks seen.size before the push and only appends when the size grew
  4. D It compares the page's index against seen.size and keeps whichever is lower

Why: The first time a fingerprint is seen, its id is pushed. Every later match just counts and skips, so the original id stays.

Q4 What does replace(/\s+/g, ' ') do to the text 'a\t b\n c'?

  1. A Removes all whitespace, giving 'abc'
  2. B Collapses every run of whitespace to a single space, giving 'a b c' correct
  3. C Replaces only the first whitespace run
  4. D Leaves the string unchanged

Why: \s+ matches any run of one-or-more whitespace chars (spaces, tabs, newlines); the global flag replaces each run with one space.

L3 — Write it from memory

One position, the code's third segment.

Discovery produced duplicate pages with inconsistent whitespace/casing. Dedupe by a normalized fingerprint (lowercase, collapse runs of whitespace to one space, trim). Keep the first occurrence's id; report kept ids and how many duplicates were removed.

Hints
  • Build the fingerprint with text.toLowerCase().replace(/\s+/g, ' ').trim() — that folds away casing and whitespace differences.
  • Track seen fingerprints in a Set; on a hit, increment a duplicate counter and continue.
  • On a miss, add the fingerprint to the Set and push the page id to the kept list — that keeps the first occurrence.
function dedupe(pages) {
  const seen = new Set();
  const kept = [];
  let dups = 0;
  for (const p of pages) {
    const key = p.text.toLowerCase().replace(/\s+/g, ' ').trim();
    if (seen.has(key)) { dups++; continue; }
    seen.add(key);
    kept.push(p.id);
  }
  return { kept, dups };
}
const pages = [
  { id: 'p1', text: 'Patient stable.' },
  { id: 'p2', text: 'patient   STABLE. ' },
  { id: 'p3', text: 'MRI ordered.' },
  { id: 'p4', text: 'Patient stable.' },
];
const result = dedupe(pages);
console.log('Kept: ' + result.kept.join(', '));
console.log('Duplicates removed: ' + result.dups);
