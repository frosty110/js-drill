for / for-of / forEach

The three ways to walk an array: classic for, for…of, and forEach. Know when each one matters.

syntax Arrays 4 concept · 2 fill-in · 1 drill

Results carried by this link

Problem

Write a function sumArr(arr) that returns the sum of all numbers. Then log sumArr([1, 2, 3, 4, 5]).

Expected output: 15

Canonical solution

// classic for — index access, supports break, fastest
for (let i = 0; i < arr.length; i++) { /* ... */ }

// for…of — values, supports break, no index by default
for (const item of arr) { /* ... */ }

// forEach — callback (item, index), NO break, returns undefined
arr.forEach((item, i) => { /* ... */ });
  • forEach can NOT be exited early with break — use for / for…of when you need that.
  • forEach returns undefined; map returns a new array.
  • Avoid for…in on arrays — it gives keys as strings and includes inherited props.

L1 — Concept questions 4

Positions 1–4 of the code's first segment. The correct option is marked; in the app the options are shuffled, but the lettering here is the authored order the code refers to.

Q1 Which iteration cannot be exited early with break?

  1. A for
  2. B for…of
  3. C forEach correct
  4. D while

Why: forEach takes a callback; break is only valid inside loop statements.

Q2 What does forEach return?

  1. A A new array
  2. B The original array
  3. C undefined correct
  4. D The number of iterations

Why: forEach is side-effect-only. Use map if you want a returned array.

Q3 Which gives you the index as the second callback parameter?

  1. A map only
  2. B forEach only
  3. C Both map and forEach correct
  4. D Neither

Why: Both pass (item, index, array) to the callback.

Q4 For maximum speed on huge arrays, prefer:

  1. A forEach (callback inlining)
  2. B Classic for (no iterator overhead) correct
  3. C for…of (uses iterator protocol)
  4. D for…in (smallest syntax)

Why: Classic for avoids the iterator protocol. For most code the difference is negligible.

L3 — Write it from memory

One position, the code's third segment.

Write a function sumArr(arr) that returns the sum of all numbers. Then log sumArr([1, 2, 3, 4, 5]).

Hints
  • Use a for…of loop.
  • Initialize an accumulator before the loop.
function sumArr(arr) {
  let sum = 0;
  for (const n of arr) sum += n;
  return sum;
}
console.log(sumArr([1, 2, 3, 4, 5]));
