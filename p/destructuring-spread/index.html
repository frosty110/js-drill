Destructuring & spread

Pull values out of arrays/objects in one line, and splat or collect with `...`.

syntax Modern Syntax 4 concept · 2 fill-in · 1 drill

Results carried by this link

Problem

Write sumAll(...args) returning the sum of any number of arguments. Log sumAll(1, 2, 3, 4, 5).

Expected output: 15

Canonical solution

// Array destructuring (commas = holes)
const [a, , b, ...rest] = [1, 2, 3, 4, 5];  // a=1, b=3, rest=[4,5]

// Object destructuring + rename + default
const { name, age = 18, addr: location } = obj;

// Spread: copy / merge / pass-as-args
const copy   = [...arr];
const merged = { ...a, ...b };               // b’s keys win on conflict
Math.max(...nums);

// Rest params
function sumAll(...args) {
  return args.reduce((a, b) => a + b, 0);
}
  • Spread is SHALLOW — nested objects/arrays still share references.
  • ...rest must be the LAST element in destructuring or in a parameter list.
  • On object spread, later keys overwrite earlier ones.

Q1 What does const [, b] = [1, 2, 3] bind b to?

  1. A 1
  2. B 2 correct
  3. C 3
  4. D undefined

Why: The leading comma is a hole skipping index 0.

Q2 After const o = {...a, ...b} with conflicting keys, which value wins?

  1. A a — earlier spreads take precedence
  2. B b correct
  3. C Whichever value is non-undefined; both defined → TypeError on duplicate key
  4. D The one whose key was defined first across both objects' insertion order

Q3 Is [...arr] a deep copy?

  1. A Yes — spread recursively clones nested arrays and objects
  2. B No, shallow correct
  3. C Deep for arrays, shallow for objects inside
  4. D Deep only when the array has no cycles; throws on circular refs

Q4 Where can ...rest appear in destructuring?

  1. A Anywhere — [...rest, last] collects all but the last element
  2. B Only at the end correct
  3. C Anywhere, but holes (commas) before it are silently dropped
  4. D At the start or end, but never in the middle
