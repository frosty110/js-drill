Map & Set

When you need O(1) lookups, reach for `Set` (uniqueness) or `Map` (key→value).

syntax Hash Structures 4 concept · 2 fill-in · 1 drill

Results carried by this link

Problem

Write dedupe(arr) returning elements in original order with duplicates removed. Log dedupe([3,1,4,1,5,9,2,6,5,3]).

Expected output: [3,1,4,5,9,2,6]

Canonical solution

// Set — unique values, O(1) has / add
const s = new Set();
s.add(1); s.has(1); s.delete(1); s.size;
new Set([1, 1, 2, 2]);  // Set {1, 2}

// Map — keyed by ANY type, preserves insertion order
const m = new Map();
m.set('k', 1);
m.get('k'); m.has('k'); m.delete('k'); m.size;
  • .size is a PROPERTY, not a method — no parens.
  • Map keys keep their type — m.set(1, "a") differs from m.set("1", "a"); Object keys are stringified.
  • Iterate a Map with for (const [k, v] of m) { ... }.

L3 — Write it from memory

One position, the code's third segment.

Write dedupe(arr) returning elements in original order with duplicates removed. Log dedupe([3,1,4,1,5,9,2,6,5,3]).

Hints
  • Track seen values in a Set.
  • Push to output only when not yet seen.
function dedupe(arr) {
  const seen = new Set();
  const out = [];
  for (const n of arr) {
    if (!seen.has(n)) { seen.add(n); out.push(n); }
  }
  return out;
}
console.log(JSON.stringify(dedupe([3,1,4,1,5,9,2,6,5,3])));
