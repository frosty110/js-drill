Counting Bits

DP on bits: counts[i] = counts[i >> 1] + (i & 1) — reuse the answer for half of i. O(n).

Problem

Write countBits(n) returning an array where counts[i] is the number of 1-bits in i for i = 0..n. Use the O(n) DP counts[i] = counts[i >> 1] + (i & 1). Log JSON.stringify(countBits(5)).

Expected output: [0,1,1,2,1,2]

Canonical solution

function countBits(n) {
  // counts[0] = 0 is the base; loop starts at 1.
  const counts = new Array(n + 1).fill(0);
  for (let i = 1; i <= n; i++) {
    // i >> 1 drops the lowest bit (i/2); i & 1 recovers it. So popcount(i) = popcount(i/2) + last bit.
    counts[i] = counts[i >> 1] + (i & 1);
  }
  return counts;
}
// Time O(n), Space O(n) for output
  • i >> 1 is integer divide by 2 — drops the lowest bit, which (i & 1) recovers.
  • counts[0] = 0 is the base case; the loop starts at 1.
  • Naive popcount per i is O(log i) → O(n log n) total; this DP is O(n).

Alternate approaches

Brian Kernighan DP (lowest-set-bit identity) O(n) / O(n)

Use this alternate if you already know the i & (i-1) Kernighan trick from hammingWeight — the recurrence counts[i] = counts[i & (i-1)] + 1 flows naturally from it. Same O(n) / O(n), different bit identity.

function countBits(n) {
  const counts = new Array(n + 1).fill(0);
  for (let i = 1; i <= n; i++) {
    // i & (i-1) clears the lowest set bit — strictly smaller than i, so safe to look up.
    counts[i] = counts[i & (i - 1)] + 1;
  }
  return counts;
}
console.log(JSON.stringify(countBits(5)));
  • i & (i-1) clears the lowest set bit of i, giving a strictly smaller index always in the table.
  • Each cell adds exactly 1 to a previously-computed value — one fewer set bit than i.
  • Equivalent O(n) as the right-shift DP; pick whichever identity you recall more easily.

Naive popcount per number (Brian Kernighan loop) O(n log n) / O(n)

Use this as the brute-force baseline you name before pitching the DP — running hammingWeight independently on each i is O(n log n) total because each call is O(set bits of i). It's instructive to show WHY the DP is better.

function countBits(n) {
  const counts = new Array(n + 1).fill(0);
  for (let i = 1; i <= n; i++) {
    let x = i;
    while (x !== 0) { x = x & (x - 1); counts[i]++; }
  }
  return counts;
}
console.log(JSON.stringify(countBits(5)));
  • Runs Brian Kernighan's popcount loop independently for every i — O(log i) per number, O(n log n) total.
  • No shared work between adjacent values — the DP avoids this waste by reusing counts[i>>1] or counts[i&(i-1)].
  • Name this brute force first in an interview; the DP is the optimization over it.
