Course Schedule

Cycle detection on a directed graph via Kahn topological sort: peel zero-indegree nodes until none remain. If all peeled, no cycle.

Problem

Write canFinish(numCourses, prerequisites) returning true iff all courses can be taken. Pair [a, b] means take b before a. Log canFinish(2, [[1, 0]]) then canFinish(2, [[1, 0], [0, 1]]).

Expected output: true false

Canonical solution

Kahn's algorithm (peel zero-indegree nodes, count them) · O(V+E) / O(V+E) (time / space)

function canFinish(numCourses, prerequisites) {
  const graph = Array.from({ length: numCourses }, () => []);
  const indeg = new Array(numCourses).fill(0);
  // [a, b] means take b before a → edge b -> a, indeg[a]++.
  for (const [a, b] of prerequisites) {
    graph[b].push(a); // edge b -> a (take b before a)
    indeg[a]++;
  }
  const queue = [];
  // Seed with every zero-indegree node — these have no prerequisites.
  for (let i = 0; i < numCourses; i++) {
    if (indeg[i] === 0) queue.push(i);
  }
  let taken = 0;
  while (queue.length) {
    const c = queue.shift();
    taken++;
    for (const n of graph[c]) {
      // Satisfying c removes one prereq from n; queue once it hits 0.
      indeg[n]--;
      if (indeg[n] === 0) queue.push(n);
    }
  }
  // Peeled every node iff acyclic; remainder, if any, lives inside a cycle.
  return taken === numCourses;
}
// Time O(V + E), Space O(V + E)
  • Kahn BFS produces a topological order as a side effect and uses no recursion stack.
  • Pair [a, b] means "take b before a" — edge b -> a in the prerequisite-to-course direction.
  • If taken < numCourses at the end, the remainder contains a cycle.

Alternate approaches

DFS 3-color cycle detection O(V+E) / O(V+E)

Use DFS when the interviewer specifically asks for the DFS-with-coloring approach, or when you're more comfortable with recursion than BFS bookkeeping. Both are O(V+E); Kahn's is generally preferred because it avoids recursion-stack depth and the topological order falls out for free.

function canFinish(numCourses, prerequisites) {
  const adj = Array.from({length: numCourses}, () => []);
  for (const [a, b] of prerequisites) adj[b].push(a);
  // 0 = white (unvisited), 1 = gray (on current path), 2 = black (safe)
  const color = new Array(numCourses).fill(0);
  function dfs(u) {
    if (color[u] === 1) return false; // re-entering a gray node = back-edge = cycle
    if (color[u] === 2) return true;  // already proven safe
    color[u] = 1;                      // mark gray — on current recursion path
    for (const v of adj[u]) {
      if (!dfs(v)) return false;
    }
    color[u] = 2;                      // mark black — subtree is cycle-free
    return true;
  }
  for (let i = 0; i < numCourses; i++) {
    if (!dfs(i)) return false;
  }
  return true;
}
console.log(canFinish(2, [[1, 0]]));
console.log(canFinish(2, [[1, 0], [0, 1]]));
  • Gray (in-progress) means 'on the current DFS path'; encountering gray again is a back-edge — a directed cycle.
  • Black (done) means the node's entire reachable subgraph is cycle-free — safe to short-circuit on re-visits.
  • Recursion depth can reach V on a chain-shaped graph; prefer Kahn's BFS if V is large.

Q1 Course Schedule reduces to which classic graph question?

  1. A Shortest path
  2. B Minimum spanning tree
  3. C Cycle detection in a directed graph correct
  4. D Connected components

Why: Each pair [a, b] is a directed edge b -> a, and a course order exists exactly when that digraph is acyclic — a cycle means some course is transitively its own prerequisite. Connected components is the undirected question, which would happily accept a 2-cycle.

Q2 In Kahn algorithm, which nodes go into the queue initially?

  1. A Nodes with zero out-degree (final courses, nothing depends on them)
  2. B Nodes with the highest indegree
  3. C Nodes with zero indegree (no remaining prerequisites) correct
  4. D Nodes whose index equals 0, then their dependents in order

Why: The seed loop pushes every i with indeg[i] === 0 — no unsatisfied prerequisite points at it, so it can be taken immediately. Seeding on out-degree instead would start at the courses nothing depends on, i.e. the wrong end of the DAG.

Q3 Time complexity?

  1. A O(V)
  2. B O(E)
  3. C O(V + E) correct
  4. D O(V * E)

Why: Building graph and indeg is one pass over the edges; the BFS then dequeues each course at most once and runs indeg[n]-- once per edge in total, so the two phases add rather than multiply.

Q4 How do you conclude that a cycle exists?

  1. A The queue runs out before all nodes are taken correct
  2. B An indegree goes negative
  3. C The graph has more edges than nodes
  4. D A node appears in the queue twice

Why: Kahn peels every zero-indegree node; if taken < numCourses at the end, the unpeeled remainder is trapped in a cycle.

Q5 Why is Union-Find NOT a correct substitute for topological sort here?

  1. A Union-Find produces a valid topological order but only when there are no shared prerequisites
  2. B Union-Find tracks undirected connectivity and cannot detect a DIRECTED cycle or produce an ordering correct
  3. C Union-Find detects cycles correctly but cannot count them, which Course Schedule requires
  4. D Union-Find requires sorted input edges, which prerequisites generally are not

Why: Course Schedule is a directed-cycle question; Union-Find only answers 'are these connected?' and would merge a->b and b->a without ever noticing the directed cycle.

Q6 A student says 'use Dijkstra to find the order.' Why is that the wrong tool?

  1. A Dijkstra runs in O(E log V) here, which is asymptotically worse than Kahn's O(V + E)
  2. B Dijkstra finds shortest weighted paths; this is an unweighted ordering/cycle-detection problem, not a distance problem correct
  3. C Dijkstra rejects graphs containing cycles, so it would crash on cyclic inputs instead of returning false
  4. D Dijkstra explores in BFS order from a single source; with multiple zero-indegree starts it would miss components

Why: There are no edge weights or 'shortest' anything here — the question is whether a valid order exists, which is topological sort / cycle detection.

Q7 The DFS alternative to Kahn detects a cycle by:

  1. A Returning to the starting node after visiting every reachable neighbor (a closed traversal walk)
  2. B Re-entering a node still marked 'in-progress' (gray) on the current recursion path correct
  3. C Discovering that the recursion's post-order index differs from its pre-order index by more than the subtree size
  4. D Finding two distinct DFS trees whose roots both reach the same node

Why: Three-color DFS marks a node gray while its subtree is being explored; encountering a gray node again means a back-edge, i.e. a directed cycle.

Q8 One concrete advantage of Kahn's BFS over the DFS-colors approach for Course Schedule II:

  1. A Kahn handles disconnected graphs natively; DFS-colors requires a separate outer loop to launch from each component
  2. B The dequeue order IS a valid topological ordering, so you get the course order for free correct
  3. C DFS-colors produces a REVERSE topological order, which would require an extra pass to flip
  4. D Kahn correctly handles self-loops; DFS-colors marks the gray node and reports a cycle prematurely

Why: Pushing each dequeued node into a result list yields the topological order directly — useful when the problem wants the actual ordering, not just a boolean.
