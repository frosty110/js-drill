House Robber

Max sum of non-adjacent elements. At each house: rob (prev2 + n) or skip (prev1). Classic 1D DP with O(1) rolling scalars.

patterns Dynamic Programming 4 concept · 1 fill-in · 1 drill

Results carried by this link

Problem

Write rob(nums) returning the max sum you can collect without taking two adjacent elements. Use O(1) space. Log rob([2, 7, 9, 3, 1]).

Expected output: 12

Canonical solution

function rob(nums) {
  // Bases both 0 — no houses robbed yet; prev1 ends up holding the answer.
  let prev2 = 0, prev1 = 0;
  // Recurrence: dp[i] = max(dp[i-1], dp[i-2] + nums[i]).
  for (const n of nums) {
    const curr = Math.max(prev1, prev2 + n);   // skip vs rob this house
    // Roll: assign prev2 BEFORE prev1, or you overwrite the value still needed.
    prev2 = prev1;
    prev1 = curr;
  }
  return prev1;
}
// Time O(n), Space O(1)
  • Recurrence: dp[i] = max(dp[i-1], dp[i-2] + nums[i]) — either skip i or take i and lose i-1.
  • Both bases are 0 (no houses robbed yet); prev1 ends up holding the answer.
  • Update order matters — assign prev2 = prev1 BEFORE prev1 = curr, or you overwrite the value you still need.

Alternate approaches

Explicit dp array (O(n) space) O(n) / O(n)

Reach for this when an interviewer wants to see the dp table before the space compression. Makes it easy to walk through the table and explain dp[i] = max(dp[i-1], dp[i-2] + nums[i]) cell by cell before the rolling-pair shortcut.

function rob(nums) {
  if (nums.length === 0) return 0;
  if (nums.length === 1) return nums[0];
  // Explicit dp table: dp[i] = max loot robbing houses 0..i with adjacency constraint.
  const dp = new Array(nums.length);
  dp[0] = nums[0];
  dp[1] = Math.max(nums[0], nums[1]);
  for (let i = 2; i < nums.length; i++) {
    dp[i] = Math.max(dp[i - 1], dp[i - 2] + nums[i]);
  }
  return dp[nums.length - 1];
}
console.log(rob([2, 7, 9, 3, 1]));
  • dp[1] is seeded as max(nums[0], nums[1]) — the best of the first two houses, since you can only pick one of them.
  • Each dp[i] records the optimal haul over the first (i+1) houses; the rolling-pair collapses this to just two scalars.
  • Transition to O(1): note dp[i] reads only dp[i-1] and dp[i-2] — identical to the climbing-stairs rolling-pair pattern.
