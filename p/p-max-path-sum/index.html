Binary Tree Maximum Path Sum

Post-order DFS. Each node returns the best single-branch gain (clamped at 0); a global tracks the best left+node+right path seen at any node.

Problem

Write maxPathSum(root) returning the maximum node-to-node path sum in a binary tree. Log maxPathSum(root) for the tree [-10, 9, 20, null, null, 15, 7].

Expected output: 42

Canonical solution

Post-order DFS with closure-state best · O(n) / O(h) (time / space)

function maxPathSum(root) {
  let best = -Infinity;
  const gain = (node) => {
    if (!node) return 0;
    const left  = Math.max(gain(node.left), 0);   // drop negative branches
    const right = Math.max(gain(node.right), 0);
    best = Math.max(best, node.val + left + right); // path through this node
    return node.val + Math.max(left, right);        // extend upward via ONE side
  };
  gain(root);
  return best;
}
// Time O(n), Space O(h)
  • Distinguish two things at each node: (a) the best path through it using BOTH children — only updates best, never returned; (b) the upward gain via ONE child — what you return to the parent.
  • Clamp each child gain at 0: a negative branch is better skipped than taken.
  • best must start at -Infinity, not 0 — paths can be entirely negative (e.g. tree [-3]).

Q1 Why is each child's gain clamped at 0 with Math.max(gain, 0)?

  1. A So a null child's gain doesn't get treated as negative infinity when added
  2. B Because a negative-sum branch is worse than not taking that branch at all correct
  3. C To keep the recursion's returned chain non-decreasing as it bubbles up the tree
  4. D Because Math.max requires its arguments to be non-negative to compare correctly

Q2 What does the recursive function RETURN to its caller?

  1. A The best path through the current node using both children
  2. B The best single-branch upward gain from this node (node.val + max(left, right)) correct
  3. C The global best so far
  4. D The sum of every node in the subtree

Why: The caller can only extend the path via ONE side; the through-node path is closed and only updates best.

Q3 Why initialize best to -Infinity rather than 0?

  1. A Math.max with 0 as a seed would silently truncate any path containing a 0-valued node
  2. B The tree could contain only negative values, so the answer can be negative correct
  3. C 0 is the identity for addition, so it would double-count single-node paths
  4. D -Infinity propagates correctly through recursive calls; 0 would be returned to the parent and used as a gain

Q4 Time complexity?

  1. A O(n log n)
  2. B O(n^2) — DFS from every node
  3. C O(n) correct
  4. D O(h) where h is tree height
