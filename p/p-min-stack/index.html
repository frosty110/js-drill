Min Stack

Parallel stack of running minimums alongside the value stack so getMin is O(1).

patterns Stack 7 concept · 1 fill-in · 1 drill

Results carried by this link

Problem

Implement a MinStack class with push, pop, top, and getMin all O(1). Then run: push(-2), push(0), push(-3), log getMin(), pop(), log top(), log getMin().

Expected output: -3 0 -2

Canonical solution

class MinStack {
  constructor() { this.vals = []; this.mins = []; }
  push(x) {
    this.vals.push(x);
    // Infinity fallback on first push — never read top of empty mins.
    const top = this.mins.length ? this.mins[this.mins.length - 1] : Infinity;
    // Push to mins on EVERY push so the two stacks stay the same length.
    this.mins.push(Math.min(top, x));
  }
  // Pop both — keeps mins[i] aligned with vals[0..i].
  pop() { this.vals.pop(); this.mins.pop(); }
  top() { return this.vals[this.vals.length - 1]; }
  getMin() { return this.mins[this.mins.length - 1]; }
}
// Time O(1) per operation, Space O(n)
  • mins[i] is the minimum of vals[0..i].
  • Push to mins on EVERY push so the two stacks stay the same length.
  • On the first push, fall back to Infinity — never read the top of an empty mins stack.

Alternate approaches

Space-optimized (push to mins only when ≤ current min) O(1) ops / O(n) worst

If the interviewer pushes on space constants and you're comfortable adding conditional logic on pop. Saves mins-stack entries in the common case where pushes are mostly larger than the running min. Use <= (not <) so duplicate mins are preserved correctly.

class MinStack {
  constructor() { this.vals = []; this.mins = []; }
  push(x) {
    this.vals.push(x);
    // Push to mins only when x is a new minimum (or ties the current min).
    if (!this.mins.length || x <= this.mins[this.mins.length - 1]) this.mins.push(x);
  }
  pop() {
    const v = this.vals.pop();
    // Only pop mins if the removed value WAS the current min.
    if (v === this.mins[this.mins.length - 1]) this.mins.pop();
  }
  top() { return this.vals[this.vals.length - 1]; }
  getMin() { return this.mins[this.mins.length - 1]; }
}
const s = new MinStack();
s.push(-2); s.push(0); s.push(-3);
console.log(s.getMin());
s.pop();
console.log(s.top());
console.log(s.getMin());
  • Use <= not < on push: duplicate mins each need a mins entry so that popping one doesn't erase a still-live min.
  • On pop, compare by value equality (===) to decide whether to also pop mins — this is the tricky conditional the parallel-stack approach avoids.
  • Strictly better space only when many pushes are larger than the running min; worst-case (monotonically decreasing input) the two stacks are still the same size.

  4. D To re-sort the stack

Why: Because push always added to both, pop must remove from both to keep the running-min stack aligned with the value stack.

Why: Pushing to mins on every push (even duplicates) means each 2 left its own running-min entry, so popping one still leaves 2 as the min.
