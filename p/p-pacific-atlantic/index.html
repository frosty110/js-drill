Pacific Atlantic Water Flow

Reverse-flood DFS from each ocean's edges; intersect the two reach-sets to find cells that drain to both oceans. O(R*C).

Problem

Write pacificAtlantic(heights) — return all cells whose water can drain to BOTH oceans (Pacific = top + left edge, Atlantic = bottom + right). Use reverse DFS from each ocean. Log JSON.stringify(result) on the classic 5x5 example.

Expected output: [[0,4],[1,3],[1,4],[2,2],[3,0],[3,1],[4,0]]

Canonical solution

Reverse multi-source DFS from each ocean, then intersect · O(R*C) / O(R*C) (time / space)

function pacificAtlantic(heights) {
  const R = heights.length, C = heights[0].length;
  // Two visited grids — same cell may be reachable from one ocean but not both.
  const pac = Array.from({length: R}, () => new Array(C).fill(false));
  const atl = Array.from({length: R}, () => new Array(C).fill(false));
  function dfs(r, c, seen, prev) {
    if (r < 0 || r >= R || c < 0 || c >= C) return;
    if (seen[r][c]) return;
    if (heights[r][c] < prev) return;          // reverse flow: must be >= neighbor
    seen[r][c] = true;
    const h = heights[r][c];
    dfs(r + 1, c, seen, h);
    dfs(r - 1, c, seen, h);
    dfs(r, c + 1, seen, h);
    dfs(r, c - 1, seen, h);
  }
  // Pacific = top + left edges; Atlantic = bottom + right. -Infinity seeds let edge cells in.
  for (let c = 0; c < C; c++) { dfs(0, c, pac, -Infinity); dfs(R - 1, c, atl, -Infinity); }
  for (let r = 0; r < R; r++) { dfs(r, 0, pac, -Infinity); dfs(r, C - 1, atl, -Infinity); }
  const out = [];
  // Answer = intersection — drains to BOTH oceans. Row-major order = sorted output.
  for (let r = 0; r < R; r++) for (let c = 0; c < C; c++) if (pac[r][c] && atl[r][c]) out.push([r, c]);
  return out;
}
// Time O(R*C), Space O(R*C)
  • Flood is REVERSED: start at ocean edges and climb to cells with height >= current — that mirrors water flowing FROM a cell TO the ocean.
  • Two separate visited grids (one per ocean) so the same cell can be explored once per ocean — intersect at the end.
  • Top + left edges touch the Pacific; bottom + right edges touch the Atlantic — corners belong to both.

Alternate approaches

BFS multi-source (iterative queue) O(R*C) / O(R*C)

Use BFS when you want to avoid recursion-stack overflow on large grids — a 200x200 grid with a tall mountain ridge can produce O(R*C) DFS depth. BFS uses an explicit queue and is otherwise structurally identical: same two visited grids, same reverse-climb rule, same intersection step.

function pacificAtlantic(heights) {
  const R = heights.length, C = heights[0].length;
  const pac = Array.from({length: R}, () => new Array(C).fill(false));
  const atl = Array.from({length: R}, () => new Array(C).fill(false));
  function bfs(seeds, seen) {
    const queue = [];
    for (const [r, c] of seeds) {
      seen[r][c] = true;
      queue.push([r, c]);
    }
    while (queue.length) {
      const [r, c] = queue.shift();
      for (const [dr, dc] of [[1,0],[-1,0],[0,1],[0,-1]]) {
        const nr = r + dr, nc = c + dc;
        if (nr >= 0 && nr < R && nc >= 0 && nc < C && !seen[nr][nc] && heights[nr][nc] >= heights[r][c]) {
          seen[nr][nc] = true;
          queue.push([nr, nc]);
        }
      }
    }
  }
  const pacSeeds = [], atlSeeds = [];
  for (let c = 0; c < C; c++) { pacSeeds.push([0, c]); atlSeeds.push([R - 1, c]); }
  for (let r = 0; r < R; r++) { pacSeeds.push([r, 0]); atlSeeds.push([r, C - 1]); }
  bfs(pacSeeds, pac);
  bfs(atlSeeds, atl);
  const out = [];
  for (let r = 0; r < R; r++) for (let c = 0; c < C; c++) if (pac[r][c] && atl[r][c]) out.push([r, c]);
  return out;
}
const heights = [[1,2,2,3,5],[3,2,3,4,4],[2,4,5,3,1],[6,7,1,4,5],[5,1,1,2,4]];

  • Mark each seed cell visited BEFORE pushing to the queue — prevents re-enqueuing edge cells when they appear in both the row and column seed loops (e.g., corners).
  • The BFS helper is a reusable function called twice — cleaner than duplicating the seeding logic for each ocean.
  • BFS explores level-by-level (by distance from edge) vs DFS depth-first; the reachability sets and output are identical.

Direction-array DFS (one neighbor loop) O(R·C) / O(R·C)

Same reverse-flow DFS as the canonical, but the four explicit recursive calls become a for…of over a deltas array — one neighbor-walk to reuse or extend to diagonals. The four-dir-neighbors idiom (Algorithms › 4-directional neighbor iteration).

const DIRS = [[1, 0], [-1, 0], [0, 1], [0, -1]];
function pacificAtlantic(heights) {
  const R = heights.length, C = heights[0].length;
  const pac = Array.from({length: R}, () => new Array(C).fill(false));
  const atl = Array.from({length: R}, () => new Array(C).fill(false));
  function dfs(r, c, seen, prev) {
    if (r < 0 || r >= R || c < 0 || c >= C) return;
    if (seen[r][c]) return;
    if (heights[r][c] < prev) return;
    seen[r][c] = true;
    const h = heights[r][c];
    for (const [dr, dc] of DIRS) dfs(r + dr, c + dc, seen, h);
  }
  for (let c = 0; c < C; c++) { dfs(0, c, pac, -Infinity); dfs(R - 1, c, atl, -Infinity); }
  for (let r = 0; r < R; r++) { dfs(r, 0, pac, -Infinity); dfs(r, C - 1, atl, -Infinity); }
  const out = [];
  for (let r = 0; r < R; r++) for (let c = 0; c < C; c++) if (pac[r][c] && atl[r][c]) out.push([r, c]);
  return out;
}

  • The per-call prev/h flow guard is unchanged — only the four calls fold into the loop.
  • DIRS at module scope avoids re-allocating the deltas array on every recursive call.
  • Row delta first, column delta second — matches the s-matrix-neighbors convention.

L1 — Concept questions 4

Positions 1–4 of the code's first segment. The correct option is marked; in the app the options are shuffled, but the lettering here is the authored order the code refers to.

Q1 Why do we DFS from the ocean edges INWARD instead of from every cell outward?

  1. A Outward DFS produces wrong answers on plateaus because equal-height cells get visited twice
  2. B It is O(R*C) instead of O((R*C)^2) — each cell is visited at most twice total correct
  3. C Inward DFS lets a single visited grid serve both oceans, halving memory
  4. D Outward DFS cannot distinguish Pacific reachability from Atlantic reachability without a separate ocean ID per cell

Why: A per-cell outward flood re-walks the same interior cells once for every start cell. Seeding from the edges instead lets pac and atl gate each cell to one visit apiece, so the seed count never multiplies the work.

Q2 Reverse-flow rule from a neighbor with height prev into current cell with height h:

  1. A h <= prev
  2. B h >= prev correct
  3. C h > prev (strict — equal heights block reverse climb just as plateaus block natural flow)
  4. D abs(h - prev) <= 1 (water climbs only one elevation step at a time)

Why: Water flows to equal-or-lower neighbors, so walking backwards from the ocean means climbing to equal-or-higher ones. The guard is if (heights[r][c] < prev) return, which admits equality — a strict > would wall off flat plateaus that really do drain.

Q3 Which edges seed the Pacific flood?

  1. A Top row + right column
  2. B Top row + left column correct
  3. C Bottom row + right column
  4. D Only the top-left corner — the DFS propagates to the rest of the Pacific edge

Why: pac is seeded by dfs(0, c, pac, …) across every column and dfs(r, 0, pac, …) down every row; the Atlantic gets the mirror pair (bottom row + right column), so the top-right and bottom-left corners are seeds of BOTH grids — that is why [0,4] and [4,0] are in the 5x5 answer no matter what the heights are.

Q4 How is the final answer built?

  1. A Union of pac and atl
  2. B Symmetric difference: cells reachable in exactly one of the two grids
  3. C Intersection: cells reachable in BOTH grids correct
  4. D Cells whose pac[r][c] index is greater than their atl[r][c] index

Why: The collection loop pushes only where pac[r][c] && atl[r][c] — the problem asks for cells draining to BOTH oceans. A union would answer 'reaches either ocean', which on the classic 5x5 is all 25 cells rather than 7.
