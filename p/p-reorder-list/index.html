Reorder List

Three classic linked-list moves stitched together: find the middle with slow/fast pointers, reverse the second half, then weave the two halves node-by-node.

Problem

Write reorderList(head) that reorders L0→L1→…→Ln to L0→Ln→L1→Ln-1→…. Use toList/toArr helpers and log JSON.stringify(toArr(reorderList(toList([1, 2, 3, 4, 5])))).

Expected output: [1,5,2,4,3]

Canonical solution

function reorderList(head) {
  if (!head || !head.next) return head;
  // 1) find middle — slow ends at the start of the second half
  let slow = head, fast = head;
  while (fast.next && fast.next.next) {
    slow = slow.next;
    fast = fast.next.next;
  }
  // 2) reverse the second half starting at slow.next
  let prev = null, curr = slow.next;
  slow.next = null;                          // cut the list in two
  while (curr) {
    const nxt = curr.next;
    curr.next = prev;
    prev = curr;
    curr = nxt;
  }
  // 3) weave: first half = head, reversed second half = prev
  let a = head, b = prev;
  while (b) {
    const an = a.next, bn = b.next;
    a.next = b;
    b.next = an;
    a = an;
    b = bn;
  }
  return head;
}
// Time O(n), Space O(1)
  • Slow/fast with the guard fast.next && fast.next.next leaves slow at the LAST node of the first half — convenient for cutting.
  • Cut with slow.next = null BEFORE reversing, so the first half terminates cleanly.
  • Weave loop condition uses b (the shorter/equal half) — when nodes are odd, the first half has one extra node already in place.
  • Cache a.next and b.next before rewiring or you lose the rest of each list.

Alternate approaches

Array-index (collect nodes, rewire with two pointers) O(n) / O(n)

Reach for this when the three-phase in-place approach feels error-prone under time pressure. It's O(n) space but much easier to reason about on a whiteboard — collect nodes into an array, then use l/r indices walking inward to rewire in one pass.

function reorderList(head) {
  if (!head || !head.next) return head;
  // Collect all nodes into an array for random access.
  const nodes = [];
  let curr = head;
  while (curr) { nodes.push(curr); curr = curr.next; }
  // Two indices walk inward, rewiring next pointers.
  let l = 0, r = nodes.length - 1;
  while (l < r) {
    nodes[l].next = nodes[r];
    l++;
    if (l === r) break;
    nodes[r].next = nodes[l];
    r--;
  }
  nodes[l].next = null;   // null-terminate the reordered list
  return head;
}
function toList(arr) { let d = { next: null }, c = d; for (const v of arr) { c.next = { val: v, next: null }; c = c.next; } return d.next; }
function toArr(h) { const o = []; while (h) { o.push(h.val); h = h.next; } return o; }
console.log(JSON.stringify(toArr(reorderList(toList([1, 2, 3, 4, 5])))));
  • The if (l === r) break guard handles odd-length lists — the middle node shouldn't point at itself.
  • nodes[l].next = null at the end is essential: the last remaining node still points at its original successor without it.
  • O(n) extra space for the array; the in-place version avoids this by composing three pointer primitives instead.
