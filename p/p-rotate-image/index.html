Rotate Image (in-place 90°)

Rotate an n×n matrix 90° clockwise in place by transposing then reversing each row.

Problem

Write rotate(matrix) that rotates an n×n matrix 90° clockwise in place. Log JSON.stringify(matrix) after rotating [[1,2,3],[4,5,6],[7,8,9]].

Expected output: [[7,4,1],[8,5,2],[9,6,3]]

Canonical solution

Transpose across the main diagonal, then reverse each row · O(n²) / O(1) (time / space)

function rotate(matrix) {
  const n = matrix.length;
  // Transpose: swap across the main diagonal. j starts at i+1 so each pair flips once.
  for (let i = 0; i < n; i++) {
    for (let j = i + 1; j < n; j++) {
      [matrix[i][j], matrix[j][i]] = [matrix[j][i], matrix[i][j]];
    }
  }
  // Transpose + row-reverse = 90° clockwise. (Reverse columns instead for counter-clockwise.)
  for (let i = 0; i < n; i++) matrix[i].reverse();
}
// Time O(n^2), Space O(1)
  • Transpose + row-reverse equals 90° clockwise. Reverse columns instead for counter-clockwise.
  • Inner loop starts at j = i + 1 so you don't swap each pair twice (and back to original).
  • In-place — no auxiliary matrix. Mutating the input is the whole point of the problem.

Alternate approaches

New-matrix (direct formula) O(n^2) / O(n^2)

Use when in-place is not required and clarity matters more than space — the direct formula out[j][n-1-i] = matrix[i][j] is immediately readable and easy to verify. Fails the in-place constraint of the standard interview problem.

function rotate(matrix) {
  const n = matrix.length;
  const out = Array.from({ length: n }, () => new Array(n));
  for (let i = 0; i < n; i++) {
    for (let j = 0; j < n; j++) {
      out[j][n - 1 - i] = matrix[i][j];
    }
  }
  for (let i = 0; i < n; i++) matrix[i] = out[i];
}
const m = [[1,2,3],[4,5,6],[7,8,9]];
rotate(m);
console.log(JSON.stringify(m));
  • Direct rotation formula: cell (i, j) lands at (j, n-1-i) after 90° CW.
  • Allocates an n×n auxiliary matrix — O(n²) extra space, which violates the typical in-place constraint.
  • Use the transpose+reverse two-pass variant whenever in-place is required.

Q1 Which two operations compose into a 90° clockwise rotation?

  1. A Reverse rows, then reverse columns
  2. B Transpose, then reverse each row correct
  3. C Transpose, then reverse each column
  4. D Reverse each row, then transpose

Why: Transposing reflects across the main diagonal; reversing each row then flips horizontally, equivalent to a 90° clockwise rotation.

Q2 Why does the transpose loop start j at i + 1?

  1. A To skip the diagonal — the diagonal cells need a separate self-swap, handled outside the loop
  2. B To avoid swapping each pair twice (which restores the original) correct
  3. C Because j = i would make the row-reverse phase double-flip the diagonal cells, undoing them
  4. D Because matrix[i][i] is read-only by convention in in-place rotations to preserve the trace

Why: With j = 0 the loop visits both (i,j) and (j,i), swapping each pair a second time and restoring the original matrix exactly. The diagonal needs no special handling — matrix[i][i] would just swap with itself.

Q3 Time and space complexity?

  1. A O(n) time, O(n) space
  2. B O(n^2) time, O(n^2) space
  3. C O(n^2) time, O(1) extra space correct
  4. D O(n^2) time, O(n) extra space for the per-row reverse buffers

Why: The transpose touches each of the ~n²/2 off-diagonal pairs once and the row reverses add another ~n²/2 swaps. Everything mutates matrix directly; Array.prototype.reverse is in-place too (it is toReversed that allocates), so only a temp swap variable is ever held.

Q4 To rotate 90° counter-clockwise with the same trick, what changes?

  1. A Apply the 90° CW algorithm three times — three CW rotations equal one CCW
  2. B Transpose, then reverse each column (or reverse rows first, then transpose) correct
  3. C Reverse the whole matrix once (treating it as a flat array of n^2 cells)
  4. D Transpose across the ANTI-diagonal instead of the main diagonal, then reverse rows

Why: Transpose is its own reflection — the second flip picks the direction. Reversing each ROW after the transpose gives clockwise; reversing each COLUMN (equivalently, reversing each row BEFORE transposing) gives counter-clockwise: [[1,2,3],[4,5,6],[7,8,9]] becomes [[3,6,9],[2,5,8],[1,4,7]].
