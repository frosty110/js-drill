Set Matrix Zeroes

If a cell is 0, zero its entire row and column — in place, with O(1) extra space, by using the first row and column as flag arrays.

Problem

Write setZeroes(matrix) that zeros every row and column containing a 0, using O(1) extra space. Log JSON.stringify(matrix) after running on [[0,1,2,0],[3,4,5,2],[1,3,1,5]].

Expected output: [[0,0,0,0],[0,4,5,0],[0,3,1,0]]

Canonical solution

Row 0 / column 0 reused as the flag arrays, two passes · O(m·n) / O(1) (time / space)

function setZeroes(matrix) {
  const m = matrix.length, n = matrix[0].length;
  // Capture row-0 / col-0 zeroness BEFORE we overwrite them with flags.
  let firstRowZero = false, firstColZero = false;
  for (let j = 0; j < n; j++) if (matrix[0][j] === 0) firstRowZero = true;
  for (let i = 0; i < m; i++) if (matrix[i][0] === 0) firstColZero = true;
  // Pass 1: use row 0 / col 0 as flag arrays for the interior.
  for (let i = 1; i < m; i++) {
    for (let j = 1; j < n; j++) {
      if (matrix[i][j] === 0) {
        matrix[i][0] = 0;
        matrix[0][j] = 0;
      }
    }
  }
  // Pass 2: read the flags and zero interior cells.
  for (let i = 1; i < m; i++) {
    for (let j = 1; j < n; j++) {
      if (matrix[i][0] === 0 || matrix[0][j] === 0) matrix[i][j] = 0;
    }
  }
  // Apply captured booleans LAST — earlier would destroy the flags Pass 2 still needs.
  if (firstRowZero) for (let j = 0; j < n; j++) matrix[0][j] = 0;
  if (firstColZero) for (let i = 0; i < m; i++) matrix[i][0] = 0;
}
// Time O(m*n), Space O(1)
  • The trick: reuse row 0 and column 0 as flag arrays, but capture their original zero state in two booleans BEFORE you start writing flags.
  • Process the interior (i, j >= 1) twice: first pass writes flags, second pass reads flags and zeros cells.
  • Apply the firstRowZero / firstColZero booleans LAST — otherwise you'd overwrite the flags you still need.

Alternate approaches

Marker Sets (O(m+n) space) O(m*n) / O(m+n)

Reach for this when interview pressure is high and the O(1) trick doesn't come to mind — two boolean arrays (one per row, one per column) make the two-pass structure obvious and are easy to reason about. The only cost is O(m+n) auxiliary space.

function setZeroes(matrix) {
  const m = matrix.length, n = matrix[0].length;
  const zeroRows = new Array(m).fill(false);
  const zeroCols = new Array(n).fill(false);
  // Pass 1: record which rows and columns contain a zero.
  for (let i = 0; i < m; i++) {
    for (let j = 0; j < n; j++) {
      if (matrix[i][j] === 0) {
        zeroRows[i] = true;
        zeroCols[j] = true;
      }
    }
  }
  // Pass 2: zero out the flagged rows and columns.
  for (let i = 0; i < m; i++) {
    for (let j = 0; j < n; j++) {
      if (zeroRows[i] || zeroCols[j]) matrix[i][j] = 0;
    }
  }
}
const g = [[0,1,2,0],[3,4,5,2],[1,3,1,5]];
setZeroes(g);
console.log(JSON.stringify(g));
  • Two explicit boolean arrays replace the implicit flags reused from row 0 / col 0 — easier to read but O(m+n) extra space.
  • Same two-pass structure as the optimal: detect zeros first, apply them second (avoids cascade writes).
  • No scalar booleans needed — the arrays are never overwritten, so row-0/col-0 ambiguity disappears.

L1 — Concept questions 4

Positions 1–4 of the code's first segment. The correct option is marked; in the app the options are shuffled, but the lettering here is the authored order the code refers to.

Q1 Why capture firstRowZero and firstColZero before scanning the interior?

  1. A Because the interior scan visits row 0 / col 0 cells first and could short-circuit before reaching real zeros
  2. B Because the first row and column get reused as flag storage and would otherwise lose their original zero info correct
  3. C Because the JS engine may reorder loop iterations and reading the scalars first guarantees a consistent snapshot
  4. D Because zeros in row 0 / col 0 trigger different row+column wipes than interior zeros do (only row, not column)

Why: Pass 1 writes flags into matrix[i][0] and matrix[0][j], so afterwards an original zero in row 0 is indistinguishable from a flag pass 1 just planted. The two booleans record that answer while it is still readable.

Q2 Space complexity of the optimal in-place approach?

  1. A O(m + n) for two separate flag arrays
  2. B O(m * n)
  3. C O(1) extra space correct
  4. D O(min(m, n)) — one flag array indexed by the smaller dimension

Why: The only extra storage is the two booleans — the flag arrays are row 0 and column 0 of matrix itself, which is the whole point of the trick. Allocating dedicated Array(m) / Array(n) flag arrays is the easier O(m + n) version.

Q3 Why must the first row / first column be zeroed LAST?

  1. A Because zeroing them first would propagate zeros via the cascade trap the two-pass design is meant to prevent
  2. B If you zero them earlier, you destroy the flags the interior pass still needs to read correct
  3. C Because the interior pass writes flags into row 0 / col 0 and they must be in a known state when written
  4. D So that the scalars firstRowZero and firstColZero can be re-derived from the matrix at the end for verification

Why: Pass 2 reads matrix[i][0] and matrix[0][j] for every interior cell, so blanking row 0 early would make every column look flagged and zero the whole matrix. The captured booleans are applied only after that last read.

Q4 Time complexity?

  1. A O(m + n)
  2. B O(m * n) correct
  3. C O((m * n)^2)
  4. D O((m + n)^2) for the cross-shaped wipe per zero

Why: Two full sweeps of the interior (plant flags, then read them) plus O(m + n) for the edge scans and wipes — that is O(m·n) overall. Nothing re-scans the grid per zero found, which is what the naive "wipe a row and column on every zero" version does.
