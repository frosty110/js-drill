Array creation

Five ways to create an array — literal, Array constructor, Array.from, Array(n).fill, and Array.of.

syntax Arrays 4 concept · 2 fill-in · 1 drill

Results carried by this link

Problem

Write range(n) returning [0, 1, ..., n-1] using Array.from. Log JSON.stringify(range(5)).

Expected output: [0,1,2,3,4]

Canonical solution

// 1) LITERAL — most common
const a = [1, 2, 3];

// 2) Array CONSTRUCTOR — surprise: one numeric arg sets LENGTH (holes)
new Array(3);        // [ <3 empty items> ]   length 3, no values
new Array(1, 2, 3);  // [1, 2, 3]             with 2+ args, just builds it

// 3) Array.of — fixes the constructor gotcha
Array.of(3);         // [3]                   always literal contents

// 4) Array(n).fill — fixed-size, populated (great for DP / matrices)
new Array(4).fill(0);                  // [0,0,0,0]
Array.from({ length: 3 }, () => []);   // [[], [], []]  — distinct refs!

// 5) Array.from — build from iterables / array-likes / with a map fn
Array.from("abc");                       // ["a","b","c"]
Array.from({ length: 5 }, (_, i) => i);  // [0,1,2,3,4]
  • new Array(3) creates HOLES, not zeros — most array methods skip holes. Use .fill(0) or Array.from to populate.
  • Array(n).fill([]) shares ONE reference across every slot. For distinct sub-arrays use Array.from({ length: n }, () => []).
  • Array.of(7) is [7]; new Array(7) is length 7 with holes.
