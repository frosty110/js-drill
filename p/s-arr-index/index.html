Indexing & .at()

Arrays are zero-indexed; use .at() for ergonomic negative indexing from the end.

syntax Arrays 4 concept · 2 fill-in · 1 drill

Results carried by this link

Problem

Write lastTwo(arr) returning the last two elements as a 2-element array using .at(). Log JSON.stringify(lastTwo([1, 2, 3, 4, 5])).

Expected output: [4,5]

Canonical solution

const arr = [10, 20, 30, 40, 50];

// Classic bracket indexing — must be a non-negative integer
arr[0];                 // 10
arr[arr.length - 1];    // 50  (verbose "last")
arr[99];                // undefined (NOT an error)

// .at() — accepts negative indices, counts from the end
arr.at(0);              // 10
arr.at(-1);             // 50  (clean "last")
arr.at(-2);             // 40
arr.at(99);             // undefined

// length is a property — assigning to it truncates or pads with empty slots
arr.length;             // 5
  • arr[-1] does NOT give the last element — it returns undefined (negative is a string key, not an index).
  • Out-of-bounds access returns undefined silently — guard or use ?? for defaults.
  • .at() is ES2022; safe in modern browsers and Node 16+. Prefer it over arr[arr.length - 1].

L1 — Concept questions 4

Positions 1–4 of the code's first segment. The correct option is marked; in the app the options are shuffled, but the lettering here is the authored order the code refers to.

Q1 What does arr[-1] return on [1, 2, 3]?

  1. A 3
  2. B 1
  3. C undefined correct
  4. D TypeError

Why: -1 isn't an index — it becomes the string key "-1", which the array doesn't have, so the read is undefined rather than an error. arr.at(-1) is the form that counts from the end.

Q2 arr.at(-1) on [10, 20, 30] returns:

  1. A 10
  2. B 30 correct
  3. C undefined
  4. D -1

Why: .at() accepts negatives and counts back from the end, so -1 is the last element — the clean replacement for arr[arr.length - 1].

Q3 What does [1, 2, 3][99] return?

  1. A 0
  2. B undefined correct
  3. C null
  4. D RangeError

Why: Out-of-bounds reads are silent in JS — a missing index is just a missing key, so you get undefined, never a RangeError. Guard with ?? when you need a default.

Q4 arr.length is a:

  1. A method — call with parens
  2. B property — no parens correct
  3. C getter that runs a count loop
  4. D constant — cannot be changed

Why: length is a plain data property — arr.length() throws. It's also writable, not constant: arr.length = 1 truncates [1,2,3] to [1] in place.

Hints
  • .at(-1) is the last element.
  • .at(-2) is the second-to-last.
function lastTwo(arr) {
  return [arr.at(-2), arr.at(-1)];
}
console.log(JSON.stringify(lastTwo([1, 2, 3, 4, 5])));
