indexOf / find

Locate values or matching elements with indexOf, includes, find, findIndex, some, and every.

syntax Arrays 4 concept · 2 fill-in · 1 drill

Results carried by this link

Problem

Write firstEven(arr) returning the first even number using find. Log firstEven([1, 3, 5, 8, 9]).

Expected output: 8

Canonical solution

const a = [10, 20, 30, 20];

// Strict-equality lookups (===)
a.indexOf(20);     // 1   — first match, or -1
a.lastIndexOf(20); // 3   — searches right-to-left
a.includes(20);    // true — boolean, NaN-aware (unlike indexOf)

// Predicate-based — pass a callback
a.find(x => x > 15);       // 20    — first match VALUE, or undefined
a.findIndex(x => x > 15);  // 1     — first match INDEX, or -1

// Quantifiers — return booleans, short-circuit
a.some(x => x > 25);   // true  — any?
a.every(x => x > 5);   // true  — all?

// Edge: NaN
[NaN].indexOf(NaN);    // -1     (=== says false for NaN)
[NaN].includes(NaN);   // true   (special-cased)
  • indexOf / lastIndexOf use === so they cannot find NaN; includes can.
  • find returns the VALUE; findIndex returns the INDEX.
  • some and every short-circuit — they stop as soon as the answer is decided.

L3 — Write it from memory

One position, the code's third segment.

Write firstEven(arr) returning the first even number using find. Log firstEven([1, 3, 5, 8, 9]).

Hints
  • find takes a predicate and returns the first value that satisfies it.
  • Even means n % 2 === 0.
function firstEven(arr) {
  return arr.find(n => n % 2 === 0);
}
console.log(firstEven([1, 3, 5, 8, 9]));
