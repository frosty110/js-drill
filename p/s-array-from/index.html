Array.from & Array.of

Build arrays without loops — `Array.from` with a mapper makes filled arrays; `Array.of` avoids the `new Array(n)` sparse-array trap.

syntax JS Toolbox 4 concept · 2 fill-in · 1 drill

Results carried by this link

Problem

Write range(n) returning [0, 1, ..., n-1] without a for-loop. Log range(6).

Expected output: [0,1,2,3,4,5]

Canonical solution

// Fill an array of length n with a mapper
Array.from({ length: 3 }, (_, i) => i * 2);  // [0, 2, 4]

// Convert any iterable (string, Set, NodeList, arguments) to an Array
Array.from('abc');                            // ['a','b','c']
Array.from(new Set([1, 1, 2]));               // [1, 2]

// Array.of — literal values, no length-vs-elements ambiguity
Array.of(3);          // [3]
new Array(3);         // [ <3 empty slots> ] — DIFFERENT!
Array.of(1, 2, 3);    // [1, 2, 3]
  • Array.from({length: n}) works because length is the only property from needs to walk an array-like.
  • new Array(3) makes 3 EMPTY slots — .map skips them. Array.from({length:3}, () => 0) gives [0,0,0].
  • The mapper gets (value, index); for {length} array-likes the value is undefined.
