Bitwise operators

Bitwise tricks unlock many interview problems — single-number, missing-number, power-of-two — and `~~x` is a fast floor for non-negative numbers.

Problem

Given [4, 1, 2, 1, 2] where every element appears twice except one, find the single number using XOR. Log it.

Expected output: 4

Canonical solution

// Operators (all on 32-bit signed ints — JS coerces numbers down first)
5 & 3;   // 1   AND   0101 & 0011 = 0001
5 | 3;   // 7   OR    0101 | 0011 = 0111
5 ^ 3;   // 6   XOR   0101 ^ 0011 = 0110
~5;      // -6  NOT   bitwise complement: ~n === -(n+1)
5 << 1;  // 10  shift left  (mul by 2)
5 >> 1;  // 2   shift right (signed; preserves sign bit)
-1 >>> 0; // 4294967295  unsigned right shift (zero-fills, gives uint32)

// Even / odd via last bit
(6 & 1) === 0;   // true — even
(7 & 1) === 1;   // true — odd

// Check bit i — is bit i set in n?
(n >> i) & 1;

// Toggle bit i
n ^ (1 << i);

// XOR swap (no temp variable)
let a = 5, b = 9;
a ^= b; b ^= a; a ^= b;
// now a = 9, b = 5

// ~~x — quick floor for non-negative numbers
~~3.7;   // 3   (same as Math.floor for positives)
~~-3.7;  // -3  (Math.floor would give -4 — different!)
  • Bitwise ops coerce numbers to **32-bit signed** integers — fractional parts and values above 2^31 - 1 get truncated/wrapped.
  • >> is the signed (arithmetic) shift — sign bit is preserved. >>> is the unsigned (logical) shift and yields a uint32.
  • ~~x truncates toward zero (Math.trunc), not toward -Infinity. Use it instead of Math.floor only when x >= 0.

Q1 Which expression checks whether n is odd?

  1. A n % 1
  2. B n & 1 correct
  3. C n | 1
  4. D n >> 1

Why: ANDing with 1 isolates the lowest bit.

Q2 What is 5 ^ 3?

  1. A 1
  2. B 6 correct
  3. C 7
  4. D 15

Why: 0101 XOR 0011 = 0110 = 6.

Q3 Which operator is the UNSIGNED right shift?

  1. A >>
  2. B >>> correct
  3. C <<<
  4. D >>=

Why: >>> zero-fills from the left, yielding a uint32.

Q4 After a ^= b; b ^= a; a ^= b; starting with a=5, b=9, what are a, b?

  1. A 5, 9
  2. B 9, 5 correct
  3. C 0, 0
  4. D 14, 14

Why: Classic XOR swap — no temp variable needed.

L3 — Write it from memory

One position, the code's third segment.

Given [4, 1, 2, 1, 2] where every element appears twice except one, find the single number using XOR. Log it.

Hints
  • x ^ x === 0; x ^ 0 === x.
  • XOR-fold the whole array — duplicates cancel, the loner remains.
function single(arr) {
  let x = 0;
  for (const n of arr) x ^= n;
  return x;
}
console.log(single([4, 1, 2, 1, 2]));
