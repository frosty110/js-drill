class basics

Classes bundle data + methods. constructor initializes state; methods live on the prototype; get/set look like properties but run code.

Problem

Write a Rectangle class with constructor (w, h) and method area(). Log new Rectangle(3, 4).area().

Expected output: 12

Canonical solution

class Counter {
  constructor(start = 0) {     // runs on new
    this.count = start;        // instance field via this
  }
  inc() {                      // method — shared on prototype
    this.count++;
    return this.count;
  }
  get value() {                // accessed as c.value (no parens)
    return this.count;
  }
  set value(x) {               // assigned as c.value = 10
    this.count = x;
  }
}

const c = new Counter(5);
c.inc();          // 6
c.value;          // 6  (getter)
c.value = 100;    // setter fires
  • Forgetting new calls the class as a function and throws a TypeError.
  • Methods on the class body do NOT need commas between them.
  • Inside a method, this is the instance — but arrow methods and detached callbacks can lose it.

L3 — Write it from memory

One position, the code's third segment.

Write a Rectangle class with constructor (w, h) and method area(). Log new Rectangle(3, 4).area().

Hints
  • Assign this.w and this.h in the constructor.
  • area() returns this.w * this.h.
class Rectangle {
  constructor(w, h) {
    this.w = w;
    this.h = h;
  }
  area() {
    return this.w * this.h;
  }
}
console.log(new Rectangle(3, 4).area());
