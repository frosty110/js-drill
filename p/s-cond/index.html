Conditionals & ternary

Branch with if/else, compress with ternary, default with || and gate with && — and know exactly which values JavaScript treats as falsy.

Problem

Write classify(n) that returns "pos" if n > 0, "neg" if n < 0, "zero" otherwise. Log classify(5), classify(-3), classify(0) on one line.

Expected output: pos neg zero

Canonical solution

// if / else if / else
if (n > 0) { /* positive */ }
else if (n < 0) { /* negative */ }
else { /* zero */ }

// Ternary — expression form, returns a value
const sign = n > 0 ? "pos" : n < 0 ? "neg" : "zero";

// Short-circuit:
//   a || b  →  a if truthy, else b   (default fallback)
//   a && b  →  a if falsy,  else b   (gate / guard)
const name = userInput || "anon";
const ok   = isReady && doWork();

// The seven falsy values: false, 0, 0n, "", null, undefined, NaN
// (-0 also exists but compares === 0, so usually counted as the same.)
// Everything else (including [], {}, "0", "false") is truthy.
  • Seven falsy values: false, 0, 0n, "", null, undefined, NaN (and -0, which === 0). Empty arrays and objects are truthy.
  • || returns the first TRUTHY operand; && returns the first FALSY (or last operand if all truthy). They short-circuit.
  • For "is this null or undefined" specifically, prefer ?? over || — otherwise 0 or "" trigger the fallback.

Q3 What does true && "ready" return?

  1. A true
  2. B false
  3. C "ready" correct
  4. D undefined

Why: && returns the first falsy operand, or the LAST when all are truthy.

Q4 The ternary cond ? a : b is:

  1. A A statement, returns nothing

  3. C An expression that always evaluates BOTH a and b before picking one

Hints
  • Three branches with early returns.
  • Or compress with a chained ternary.
function classify(n) {
  if (n > 0) return "pos";
  if (n < 0) return "neg";
  return "zero";
}
