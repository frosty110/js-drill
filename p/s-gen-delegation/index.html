Generator delegation (yield*)

`yield*` delegates iteration to another iterable — generators, arrays, strings — letting you compose iterators without manual loops.

syntax Iterators & Generators 4 concept · 2 fill-in · 1 drill

Results carried by this link

Problem

Write function* combined() that delegates to two inner generators: evens() yielding 2,4 and odds() yielding 1,3. Order them evens-then-odds. Log [...combined()].join('-').

Expected output: 2-4-1-3

Canonical solution

// yield* hands off control to another iterable.
function* inner() {
  yield 1;
  yield 2;
}
function* outer() {
  yield 0;
  yield* inner();   // delegates: emits 1, then 2
  yield 3;
}
[...outer()]; // [0, 1, 2, 3]

// Works on ANY iterable, not just generators.
function* fromArr() {
  yield* [10, 20, 30];
  yield* 'ab';      // strings are iterable: 'a', 'b'
}
[...fromArr()]; // [10, 20, 30, 'a', 'b']

// Without yield*, you'd need a manual loop:
// for (const v of inner()) yield v;
  • yield* iterable is shorthand for for (const v of iterable) yield v; — including completion handling.
  • The delegated iterable can be a generator, array, string, Set, Map, or anything with [Symbol.iterator].
  • yield (no star) on an iterable would emit the iterable itself as one value — use yield* to flatten.

Hints
  • Declare both inner generators with function*.
  • Inside combined, use yield* evens() then yield* odds().
  • Spread the generator and call .join('-') on the resulting array.
function* evens() {
  yield 2;
  yield 4;
}
function* odds() {
  yield 1;
  yield 3;
}
function* combined() {
  yield* evens();
  yield* odds();
}
console.log([...combined()].join('-'));
