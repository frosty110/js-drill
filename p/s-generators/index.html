Generators (function*, yield)

A `function*` declaration returns a generator — a lazy iterator you advance with `.next()`, pausing at each `yield`.

Problem

Write a generator range(n) that yields 0, 1, ..., n-1. Log [...range(4)] as JSON.

Expected output: [0,1,2,3]

Canonical solution

// A generator function returns a generator object.
function* counter() {
  yield 1;
  yield 2;
  yield 3;
}

const g = counter();
g.next(); // { value: 1, done: false }
g.next(); // { value: 2, done: false }
g.next(); // { value: 3, done: false }
g.next(); // { value: undefined, done: true }

// Generators are iterable — for..of and spread work directly.
for (const n of counter()) { /* 1, 2, 3 */ }
[...counter()]; // [1, 2, 3]

// Lazy: nothing runs until you call .next().
function* infinite() {
  let i = 0;
  while (true) yield i++;
}
  • The asterisk attaches to the keyword: function* name(), not function *name() by convention.
  • Calling a generator function does NOT run its body — it returns a generator object. The body runs lazily on .next().
  • Each .next() returns { value, done }. After the final yield, the next call returns { value: undefined, done: true }.

Q1 What does calling a generator function (e.g. counter()) actually return?

  1. A The first yielded value
  2. B A generator object (iterator) — the body has not run yet correct
  3. C An array of all yielded values
  4. D A Promise that resolves to the yields

Why: Generator calls return an iterator immediately; the body runs lazily.

Q2 What is the shape of the object returned by .next()?

  1. A { value, done } correct
  2. B { value, done, index } — index tracks how many yields have fired
  3. C Just the yielded value — done is signalled by throwing StopIteration
  4. D A Promise resolving to { value, done } — .next() is always async

Why: A generator object satisfies the plain iterator protocol — the same { value, done } record a hand-written next() returns. Only async function* wraps it in a Promise.

Q3 After the last yield runs, what does the next .next() call return?

  1. A { value: lastYield, done: true }
  2. B { value: undefined, done: true } correct
  3. C It throws a RangeError
  4. D { value: null, done: false }

Why: Once the function completes without further yields, value is undefined and done flips to true.

Q4 Which syntax declares a generator function?

  1. A function* gen() { ... } correct
  2. B async function gen() { ... }
  3. C function gen*() { ... }
  4. D generator gen() { ... }

Why: The star attaches to the function keyword, before the name — function gen*() is a SyntaxError. async function gives back a Promise, not an iterator.

L3 — Write it from memory

One position, the code's third segment.

Write a generator range(n) that yields 0, 1, ..., n-1. Log [...range(4)] as JSON.

Hints
  • Declare with function* range(n).
  • Loop from 0 to n-1 and yield i each step.
  • Spread the generator into an array to materialize all values.
function* range(n) {
  for (let i = 0; i < n; i++) yield i;
}
console.log(JSON.stringify([...range(4)]));
