JSON.parse / stringify

Serialize and deserialize structured data — the API has more knobs than people remember (indent, replacer, reviver) and a handful of foot-guns.

Problem

Deep-clone an object via JSON. Define clone(o) and prove the clone is a separate reference. Log the cloned value's JSON and whether clone(obj) === obj.

Expected output: {"a":1,"b":[2,3]} false

Canonical solution

// Basic round-trip
const obj = { a: 1, b: [2, 3] };
const s = JSON.stringify(obj);          // '{"a":1,"b":[2,3]}'
const back = JSON.parse(s);             // { a: 1, b: [2, 3] }

// Pretty-print with indent (3rd arg)
JSON.stringify(obj, null, 2);           // 2-space indent

// Replacer: filter or transform on the way out
JSON.stringify({ a: 1, pw: 'x' }, (k, v) => k === 'pw' ? undefined : v);

// Reviver: transform on the way in
JSON.parse('{"d":"2024-01-01"}', (k, v) => k === 'd' ? new Date(v) : v);

// PITFALLS
JSON.stringify({ a: undefined, b: NaN });  // '{"b":null}' — undefined dropped, NaN→null
JSON.stringify([undefined]);               // '[null]'
// Circular refs THROW: JSON.stringify(obj) where obj.self = obj
  • undefined is dropped from objects but becomes null in arrays. NaN and Infinity also stringify to null.
  • Circular references throw TypeError: Converting circular structure to JSON.
  • Replacer can be an array of keys to whitelist: JSON.stringify(o, ['a','b']).

Q1 What does JSON.stringify({a: undefined, b: 1}) produce?

  1. A '{"a":undefined,"b":1}'
  2. B '{"a":null,"b":1}'
  3. C '{"b":1}' correct
  4. D throws

Why: undefined values on object keys are dropped entirely.

Q2 What does JSON.stringify([undefined, NaN]) produce?

  1. A '[undefined,NaN]'
  2. B '[null,null]' correct
  3. C '[]'
  4. D throws

Why: In arrays, both become null to preserve indices.

Q3 Which argument controls indentation?

  1. A 1st
  2. B 2nd
  3. C 3rd correct
  4. D 4th

Why: JSON.stringify(value, replacer, indent).

Q4 Stringifying an object with a circular reference will:

  1. A Return '[Circular]'
  2. B Return '{}'
  3. C Throw a TypeError correct
  4. D Silently drop the cycle

Why: JSON.stringify has no cycle tracking — it throws TypeError: Converting circular structure to JSON, so guard before serializing anything graph-shaped.

L3 — Write it from memory

One position, the code's third segment.

Deep-clone an object via JSON. Define clone(o) and prove the clone is a separate reference. Log the cloned value's JSON and whether clone(obj) === obj.

Hints
  • JSON.parse(JSON.stringify(x)) is the quickest deep clone for plain data.
  • Note: it drops functions, undefined, and breaks Dates / Maps — fine for JSON-shaped data.
function clone(o) {
  return JSON.parse(JSON.stringify(o));
}
const obj = { a: 1, b: [2, 3] };
const c = clone(obj);
console.log(JSON.stringify(c));
console.log(c === obj);
