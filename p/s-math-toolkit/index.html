Problem

Given [12, -7, 3, 25, -1], log on separate lines: the sum of absolute values, the min, the max.

Expected output: 48 -7 25

Canonical solution

// Min / max over an array — use spread
Math.min(...[3, 1, 4, 1, 5]);    // 1
Math.max(...[3, 1, 4, 1, 5]);    // 5
Math.min();                       // Infinity  (empty)
Math.max();                       // -Infinity (empty)

// Rounding modes
Math.floor(2.9);   //  2
Math.ceil(2.1);    //  3
Math.round(2.5);   //  3   (half rounds toward +Infinity)
Math.round(-2.5);  // -2   (NOT -3)
Math.trunc(2.9);   //  2   (chop fraction, sign-preserving)
Math.trunc(-2.9);  // -2

// Absolute value, sign
Math.abs(-7);      // 7
Math.sign(-3);     // -1   (returns -1, 0, +1)

// Power, roots, logs, hypot
Math.pow(2, 10);   // 1024  (or 2 ** 10)
Math.sqrt(16);     // 4
Math.log2(8);      // 3
Math.hypot(3, 4);  // 5     (sqrt of sum of squares)
  • Math.max(arr) (no spread) returns NaN — arr becomes one argument and is coerced to a number.
  • Math.round rounds half toward +Infinity, so Math.round(-2.5) is -2, not -3.
  • Use Math.trunc when you want to discard the fractional part regardless of sign; Math.floor rounds toward -Infinity.

Q1 How do you get the max of an array arr?

  1. A Math.max(arr)
  2. B Math.max(...arr) correct
  3. C arr.max()
  4. D Math.maxOf(arr)

Why: Math.max is variadic — spread the array into its arguments.

Q2 What is Math.round(-2.5)?

  1. A -3
  2. B -2 correct
  3. C -2.5
  4. D NaN

Why: JS rounds halves toward +Infinity.

Q3 Which function chops the fractional part without changing sign?

  1. A Math.floor
  2. B Math.ceil
  3. C Math.trunc correct
  4. D Math.round

Why: Math.floor(-2.9) is -3; Math.trunc(-2.9) is -2.

Q4 What does Math.max() return?

  1. A 0
  2. B undefined
  3. C Infinity
  4. D -Infinity correct

Why: Identity element for max — anything is larger than -Infinity.

Given [12, -7, 3, 25, -1], log on separate lines: the sum of absolute values, the min, the max.

Hints
  • Reduce with Math.abs for the first line.
  • Spread the array into Math.min and Math.max.
const arr = [12, -7, 3, 25, -1];
const absSum = arr.reduce((a, b) => a + Math.abs(b), 0);
console.log(absSum);
console.log(Math.min(...arr));
console.log(Math.max(...arr));
