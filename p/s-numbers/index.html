Numbers & Math

JavaScript has one number type (double-precision float). Math.* gives you the calculator; parseInt vs Number gives you the parser.

Problem

Write avg(arr) that returns the rounded mean of an array. Log avg([1, 2, 3, 4, 5]).

Expected output: 3

Canonical solution

// One number type — integers and floats live together
Number.MAX_SAFE_INTEGER;   // 9007199254740991 (2^53 - 1)
0.1 + 0.2;                 // 0.30000000000000004  ← float math

// Rounding
Math.floor(3.7);   // 3  — toward -Infinity
Math.ceil(3.2);    // 4  — toward +Infinity
Math.round(3.5);   // 4  — half rounds toward +Infinity
Math.abs(-7);      // 7

// Min / max — pair with spread to work on arrays
Math.max(1, 5, 3);          // 5
Math.max(...[1, 5, 3]);     // 5
Math.min(...[1, 5, 3]);     // 1

// Parsing strings to numbers
Number("42");      // 42
Number("42px");    // NaN          ← strict
parseInt("42px");  // 42           ← lenient, stops at first non-digit
parseInt("ff", 16);// 255          ← always pass the radix
Number.isNaN(NaN); // true
  • Math.max() with NO arguments returns -Infinity; Math.min() returns +Infinity. Spread an array in to compare its values.
  • parseInt is lenient ("42px" → 42); Number is strict ("42px" → NaN). Pick by intent.
  • Floats lose precision: 0.1 + 0.2 !== 0.3. For money, work in integer cents.

Q1 What does Math.max() return when called with NO arguments?

  1. A 0
  2. B undefined
  3. C -Infinity correct
  4. D It throws TypeError

Why: Surprise: Math.max() returns -Infinity, Math.min() returns +Infinity. Useful as initial accumulators.

Q2 How do you get the max of an array nums?

  1. A Math.max(nums)
  2. B Math.max(...nums) correct
  3. C nums.max()
  4. D Math.maxOf(nums)

Why: Math.max takes individual args, so spread the array. Math.max(nums) coerces the array to NaN.

Q3 Number("42px") returns:

  1. A 42
  2. B "42px"
  3. C NaN correct
  4. D 0

Why: Number() is strict; parseInt("42px") would return 42.

Q4 0.1 + 0.2 === 0.3 is:

  1. A true
  2. B false — float precision correct
  3. C true only in strict mode
  4. D undefined

Why: IEEE-754 doubles cannot represent 0.1 or 0.2 exactly; the sum is 0.30000000000000004.

L3 — Write it from memory

One position, the code's third segment.

Write avg(arr) that returns the rounded mean of an array. Log avg([1, 2, 3, 4, 5]).

Hints
  • Reduce to sum, then divide by length.
  • Math.round on the result.
function avg(arr) {
  const sum = arr.reduce((a, b) => a + b, 0);
  return Math.round(sum / arr.length);
}
console.log(avg([1, 2, 3, 4, 5]));
