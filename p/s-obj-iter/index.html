Problem

Write invert(obj) that swaps keys and values. Log JSON.stringify(invert({ a: 1, b: 2, c: 3 })).

Expected output: {"1":"a","2":"b","3":"c"}

Canonical solution

const o = { a: 1, b: 2, c: 3 };

// Three core helpers — all return ARRAYS (own enumerable string keys)
Object.keys(o);     // ["a","b","c"]
Object.values(o);   // [1, 2, 3]
Object.entries(o);  // [["a",1], ["b",2], ["c",3]]

// Iterate with destructured entries
for (const [k, v] of Object.entries(o)) {
  // k = "a", v = 1, ...
}

// for…in — keys only, INCLUDES inherited enumerable properties
for (const k in o) { /* k = "a", "b", "c" */ }

// Build an object back from entries
Object.fromEntries([["x", 1], ["y", 2]]);  // { x: 1, y: 2 }
  • for…in walks the prototype chain — it can surface inherited keys. Object.keys does NOT.
  • Numeric-looking keys are iterated in ascending numeric order, then string keys in insertion order.
  • Entries pair beautifully with destructuring: for (const [k, v] of Object.entries(o)).

Positions 1–4 of the code's first segment. The correct option is marked; in the app the options are shuffled, but the lettering here is the authored order the code refers to.

Q1 Object.entries({a:1, b:2}) returns what shape?

  1. A { a: 1, b: 2 }
  2. B ["a", "b"]
  3. C [["a", 1], ["b", 2]] correct
  4. D [1, 2]

Why: entries returns an array of [key, value] pairs — the shape that destructures straight into for (const [k, v] of ...). keys gives ["a","b"] and values gives [1,2].

Q2 Which iterator can pick up INHERITED keys?

  1. A Object.keys
  2. B Object.values
  3. C for…in correct
  4. D Object.entries

Why: for…in walks the prototype chain; the Object.* helpers stop at own keys.

Q3 How do you rebuild an object from [["x",1],["y",2]]?

  1. A Object.from(...)
  2. B Object.fromEntries(...) correct
  3. C new Object(...)
  4. D Object.assign(...)

Why: Object.fromEntries is the exact inverse of Object.entries. There is no Object.from, and Object.assign({}, pairs) copies by array INDEX — you'd get {"0":["x",1],"1":["y",2]}.

Q4 Inside for (const [k, v] of Object.entries(o)), what is v?

  1. A The key
  2. B The value correct
  3. C The index
  4. D [key, value] pair

Why: Each entry IS the [key, value] pair, so the destructuring binds k to the key and v to the value — for…of over entries never surfaces an index.

L3 — Write it from memory

One position, the code's third segment.

Write invert(obj) that swaps keys and values. Log JSON.stringify(invert({ a: 1, b: 2, c: 3 })).

Hints
  • Iterate Object.entries.
  • Assign out[value] = key.
function invert(obj) {
  const out = {};
  for (const [k, v] of Object.entries(obj)) {
    out[v] = k;
  }
  return out;
}
console.log(JSON.stringify(invert({ a: 1, b: 2, c: 3 })));
