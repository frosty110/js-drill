Array-as-queue

A plain array becomes a queue with push + shift — FIFO, but shift is O(n).

patterns Algorithms 4 concept · 2 fill-in · 1 drill

Results carried by this link

Problem

Write processQueue(items) that copies items into a queue, drains it FIFO, and returns the drained order. Log JSON.stringify(processQueue(["a", "b", "c"])).

Expected output: ["a","b","c"]

Canonical solution

// Queue = FIFO (First In, First Out)
const queue = [];

queue.push("a");   // ["a"]
queue.push("b");   // ["a", "b"]
queue.push("c");   // ["a", "b", "c"]

queue.shift();     // "a" → queue is ["b", "c"]
queue.shift();     // "b" → queue is ["c"]

// Peek front without removing
queue[0];          // "c"

// Classic use: BFS / level-order
//   while (queue.length) {
//     const node = queue.shift();
//     // visit node, enqueue children
//   }

// PERFORMANCE: Array.shift is O(n) — it re-indexes every remaining element.
// For huge queues, use a head pointer or a linked-list deque.
  • push + shift gives FIFO, but shift is O(n) — fine for interviews, slow for millions.
  • For high-throughput queues, swap to a two-stack or head-index trick for amortized O(1).
  • When the problem says "process in arrival order" or BFS, reach for a queue.
  • Time O(n²) naive (n shifts each O(n)), O(n) with head-pointer. Space O(n).

Alternate approaches

Head-pointer (O(n) dequeue total) O(n) / O(n)

Use when the queue could hold tens of thousands of items and shift would make the drain O(n²). Advance an integer index instead of removing elements — no re-indexing, dequeue is O(1). Trade-off: the backing array is never garbage-collected until you're done.

function processQueue(items) {
  const queue = [...items];
  const out = [];
  let head = 0;
  while (head < queue.length) {
    out.push(queue[head++]);
  }
  return out;
}
console.log(JSON.stringify(processQueue(["a", "b", "c"])));
  • head++ advances a read cursor without re-indexing — dequeue is O(1) instead of O(n).
  • The backing array grows but never shrinks during the drain; this is fine unless memory is tight.
  • BFS uses exactly this pattern: seed queue = [start], let head = 0, then const cur = queue[head++] inside the loop.

  2. B Amortized O(1) — V8 uses a head-pointer optimization internally
  3. C O(n) — re-indexes every element correct

  3. C In-order tree traversal — the queue holds the current ancestor path
  4. D Dijkstra's algorithm on weighted graphs — the queue orders nodes by distance

function processQueue(items) {
  const queue = [...items];
  const out = [];
  while (queue.length) {
    out.push(queue.shift());
  }
  return out;
}
