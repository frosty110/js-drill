Problem

Write slugify(s) that lowercases the string, replaces every run of non-alphanumeric characters with a single -, and trims leading/trailing -. Log slugify(' Hello, World!! ').

Expected output: hello-world

Canonical solution

// Literal form vs constructor form
const re1 = /\d+/g;
const re2 = new RegExp('\\d+', 'g');   // double-escape inside a string

// .test — boolean
/^\d+$/.test('123');           // true
/^\d+$/.test('12a');           // false

// .match — first match (no g) OR array of matches (with g)
'foo123bar45'.match(/\d+/);    // ['123', index: 3, ...]
'foo123bar45'.match(/\d+/g);   // ['123', '45']

// .replace — replaces FIRST match unless flag g
'a-b-c'.replace('-', '_');     // 'a_b-c'
'a-b-c'.replace(/-/g, '_');    // 'a_b_c'

// Capture groups → $1, $2 ... in replacement
'John Doe'.replace(/(\w+) (\w+)/, '$2 $1');  // 'Doe John'

// replaceAll — string arg works without /g
'a-b-c'.replaceAll('-', '_');  // 'a_b_c'

// Common flags: g (global), i (ignore case), m (multiline ^/$ per line)
  • String.prototype.replace with a plain string replaces only the FIRST occurrence — use /g or .replaceAll.
  • Inside a new RegExp('...') string, you must double-escape — '\\d+' matches one digit-class.
  • 'abc'.match(/x/) returns null (not []) when there is no match — guard before indexing.

Q1 Which flag makes a regex match all occurrences in .match / .replace?

  1. A i
  2. B g correct
  3. C m
  4. D s

Why: g is the global flag. i ignores case, m re-points ^/$ at line boundaries, and s lets . match a newline — none of them affect how many matches you get.

Q2 What does 'a-b'.replace('-', '_') return when the input is 'a-b-c'?

  1. A 'a_b_c'
  2. B 'a_b-c' correct
  3. C 'a-b-c'
  4. D throws

Why: String-arg replace only swaps the first occurrence.

Q3 How do you reference the second capture group in a replacement string?

  1. A \2
  2. B $2 correct
  3. C %2
  4. D #2

Why: Replacement strings use $1/$2. \2 is the backreference syntax inside the PATTERN — in the replacement it stays a literal backslash-2.

Q4 What does 'abc'.match(/x/) return when there is no match?

  1. A []
  2. B [null]
  3. C null correct
  4. D undefined

Why: Guard for null before indexing into the result.

L3 — Write it from memory

One position, the code's third segment.

Write slugify(s) that lowercases the string, replaces every run of non-alphanumeric characters with a single -, and trims leading/trailing -. Log slugify(' Hello, World!! ').

Hints
  • Use [^a-z0-9]+ with the g flag to collapse runs.
  • Trim leading/trailing dashes with ^-+|-+$.
function slugify(s) {
  return s.toLowerCase()
    .replace(/[^a-z0-9]+/g, '-')
    .replace(/^-+|-+$/g, '');
}
console.log(slugify('  Hello, World!! '));
