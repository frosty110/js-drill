String methods

Core string methods for slicing, splitting, searching, casing, trimming, and replacing — the daily-driver toolkit.

Problem

Write normalize(s) that trims, lowercases, and replaces ALL whitespace runs with "-". Log normalize(" Hello World ").

Expected output: hello-world

Canonical solution

// slice(start, end?) — non-mutating substring (end exclusive)
"Hello, World".slice(7);        // "World"
"Hello, World".slice(0, 5);     // "Hello"

// split(sep) → array; includes / indexOf → search
"a,b,c".split(",");             // ["a","b","c"]
"hello".includes("ell");        // true
"hello".indexOf("l");           // 2 (-1 if missing)

// case + whitespace
"ABC".toLowerCase();            // "abc"
"abc".toUpperCase();            // "ABC"
"  hi  ".trim();                // "hi"

// replace(needle, value) — first match only by default
"a-b-c".replace("-", "_");      // "a_b-c"
"a-b-c".replace(/-/g, "_");     // "a_b_c"  (use /g for all)

// repeat
"ab".repeat(3);                 // "ababab"
  • Strings are IMMUTABLE — every method returns a new string; the original is unchanged.
  • replace with a plain string replaces only the FIRST match. Use a /pattern/g regex (or replaceAll) for every match.
  • indexOf returns -1 when not found; includes returns a boolean. Pick by what you actually need.

Q1 What does "Hello, World".slice(7) return?

  1. A "Hello, "
  2. B "World" correct
  3. C "o, World"
  4. D "World!"

Why: slice(7) starts at index 7 and runs to the end.

Q2 How many matches does "a-b-c".replace("-", "_") swap?

  1. A All of them
  2. B None
  3. C Only the first correct
  4. D Only the last

Why: Plain-string replace swaps only the first match. Use /g or replaceAll for all.

Q3 Does .toUpperCase() mutate the original string?

  1. A Yes
  2. B No — strings are immutable correct
  3. C Only if the string was declared with let (the binding is mutable)
  4. D Only when the string contains lowercase chars; otherwise it is a no-op AND mutates

Why: Every string method returns a fresh string and leaves the receiver alone, so you must use the return value — that is why the L3 normalize chains trim().toLowerCase().replace() instead of calling them for effect. let vs const decides whether you can REBIND the variable, not whether the characters can be edited.

Q4 What does "hello".indexOf("z") return?

  1. A undefined
  2. B 0
  3. C -1 correct
  4. D It throws

Why: indexOf returns -1 when not found.

L3 — Write it from memory

One position, the code's third segment.

Write normalize(s) that trims, lowercases, and replaces ALL whitespace runs with "-". Log normalize(" Hello World ").

Hints
  • Chain trim → toLowerCase → replace.
  • Use a /\s+/g regex to catch every whitespace run.
function normalize(s) {
  return s.trim().toLowerCase().replace(/\s+/g, "-");
}
console.log(normalize("  Hello World  "));
