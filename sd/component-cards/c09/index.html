How callers talk to you, and how you talk back. 7 building blocks drilled by recall: the signal that says reach for one, what it costs, how it breaks, which sibling rules it out, and what it is doing across the canonical problems.

Key ideas

  • WebSockets / Persistent Connections — A long-lived bidirectional connection, so the server can push without the client asking and latency is one hop rather than one poll interval.
  • Server-Sent Events — A one-way stream of events over a normal HTTP response, with browser-native reconnect and event ids for resumption.
  • REST — Resource-oriented HTTP with standard verbs, status codes and cacheable GETs — the default public API shape.
  • gRPC — Binary RPC over HTTP/2 with an IDL-defined contract, code generation, streaming and multiplexing.
  • GraphQL — A single endpoint where the client declares exactly which fields of a graph it wants, in one round trip.
  • Webhooks — Pushing events to a URL the customer registered, so their server learns about changes without polling yours.
  • Cursor Pagination — Returning a page plus an opaque cursor pointing at the last item, so the next page seeks rather than counting from the start.
