Transactional Outbox / CDC

Writing the event into the same database transaction as the state change, then shipping it from the table or the write-ahead log — so the event and the data cannot disagree.

Async & Messaging supporting 4 problems

Reach for it when

  • A state change must reliably produce an event and you cannot afford to lose either
  • The prompt has a dual-write problem: database plus queue, with no distributed transaction available
  • Downstream systems (search index, cache, analytics) must converge on the database's truth

Don't reach for it when

  • The event does not need to be as durable as the write; a direct publish is far less machinery
  • You do not own the database, or cannot run a relay next to it

What it costs you

  • An outbox table plus a relay process, or a CDC pipeline to operate
  • Additional write volume and a table that needs pruning
  • Events carry database shape, so the schema becomes an external contract

How it breaks

  • Relay lag making 'reliable' events arbitrarily late
  • Outbox table growing without bound because pruning was never built
  • CDC replaying from an old log position and re-emitting a flood of duplicates

Instead, consider

  • Pub/Sub — Direct publish when losing the occasional event is genuinely acceptable.
  • Saga — For multi-service workflows, the outbox is how each step reliably announces it happened.

Used in 4 design problems

  • Design a Payment System (Wallet / Ledger) — The ledger write and its event commit in one transaction, so a payment can never be recorded without the event telling everyone else.
  • Design a Prescription Drug Marketplace — Each workflow step announces completion from the same transaction that performed it, which is what makes the saga recoverable.
  • Design a Search Engine — Index updates are driven from the document store's change log, so the index converges on the source of truth without a dual write.
  • Design a Feature Store — Feature updates are driven from the source system's change log, so the online store converges on truth without a dual write.
