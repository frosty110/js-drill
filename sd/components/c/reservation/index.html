Reservation / Hold

Temporarily claiming a scarce resource with an expiry, so a user can complete a multi-step flow without it being sold underneath them.

Reach for it when

  • Inventory is finite and the purchase flow takes more than one request — seats, rooms, drivers
  • Overselling is unacceptable but locking for the whole session is unacceptable too
  • The prompt describes a checkout, booking or matching flow

Don't reach for it when

  • The resource is effectively unlimited; a hold is pure overhead
  • The flow is a single atomic request — just do the transaction

What it costs you

  • Expiry handling: something must reliably release abandoned holds
  • Held-but-unsold inventory is real lost revenue during high demand
  • Users see 'available' counts that include or exclude holds, and you must decide which

How it breaks

  • Holds never expiring because the sweeper failed, silently freezing inventory
  • Race between expiry and confirmation, releasing something that was just purchased
  • Hold count not enforced atomically, so concurrent requests both succeed and oversell

Instead, consider

  • Distributed Lock — A lock blocks others outright; a reservation is a lock with an owner, an expiry and a business meaning.
  • Saga — When the hold spans several services, the reservation becomes one step of a saga.

Used in 4 design problems

  • Design a Ride-Sharing Service — A driver is held for a rider while the offer is outstanding, so two riders cannot be matched to the same car.
  • Design a Ticket Booking System (Ticketmaster-style) — Seats are held for the duration of checkout with an expiry — the mechanism that prevents overselling without locking for the whole session.
  • Design a Prescription Drug Marketplace — Stock is held while the order and its authorisation clear, since dispensing against inventory that is already gone is not recoverable.
  • Design a Human Review Queue — A claimed item is held under an expiring lease, which gives at-most-one-active-reviewer without a lock service and returns the item automatically when someone closes their laptop.
