  2. L4 load balancers route on — L4 load balancers route on transport info (IP/port) and connections/NAT; L7 load balancers understand HTTP and can route on path, header, or cookie and terminate TLS.
  3. Real systems often layer both — Real systems often layer both: L4 for raw distribution/DDoS absorption, L7 behind it for smart routing.
  4. If I just need to — If I just need to spread raw connections cheaply across a stateless fleet, or handle non-HTTP traffic, L4 is faster and simpler — and it's common to run L4 at the edge with L7 behind it.
