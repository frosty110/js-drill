  3. Stale-while-revalidate returns the stale entry — Stale-while-revalidate returns the stale entry right away to keep latency low and kicks off an async refresh so the next reader gets fresh data, avoiding both the miss latency and the stampede.
  4. Cache-aside (lazy loading) — Cache-aside (lazy loading): the app checks the cache, and on a miss loads from the DB and populates the cache itself; the cache never talks to the DB.
