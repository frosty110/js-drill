Trace the flow

  1. Eviction policies (LRU, LFU, FIFO — Eviction policies (LRU, LFU, FIFO, TTL/random) decide who leaves when the cache is full; cache invalidation is famously one of the two hard problems.
  2. Write-through favors consistency — Write-through favors consistency; write-back favors throughput but risks loss and reordering.
  3. Cache expensive reads close to — Cache expensive reads close to demand, then make staleness and invalidation explicit design decisions.
  4. Read-through and write-through push that — Read-through and write-through push that logic into the cache layer; write-through writes cache and DB synchronously (fresh but slower writes).
  5. A cache stampede/thundering herd happens — A cache stampede/thundering herd happens when a hot key expires and many requests hit the origin at once; mitigate with per-key locking, request coalescing, jittered TTLs, early recomputation, or stale-while-revalidate.
