One atomic token-bucket decision

Decision flow study sheet

What this sheet shows

The stored state is tokens plus the last refill timestamp. One atomic script computes elapsed refill, caps the bucket at capacity, spends the request cost when possible, and returns the remaining budget and reset estimate.

Trace refill, spend, allow, and Retry-After calculation as one race-free state transition.

Trace the flow

  1. Read inputs — Use key, capacity B, refill rate r, cost c, and a monotonic server-side time source.
  2. Refill — tokens = min(B, tokens + r × elapsed).
  3. Decide — If tokens ≥ c, subtract c and allow; otherwise preserve state and reject.
  4. Explain — Return remaining tokens and Retry-After = ceil((c − tokens) ÷ r).
  5. Expire idle keys — Set a TTL long enough for a full refill so inactive identities do not consume memory forever.
