Primitive Selection Map

System map study sheet

What this sheet shows

Consistent hashing places keys and nodes on a ring so adding/removing a node remaps only ~K/N keys instead of nearly all of them.

Trace the flow

  1. Key / request — hash or shard; then continue to Placement primitive.
  2. Placement primitive — quorum / leader; then continue to Coordination primitive.
  3. Coordination primitive — read + write; then continue to Replicated storage.
  4. Replicated storage — Observe the result, enforce the contract, and feed failures back into the design.

What this belongs to

The low-level distributed-systems building blocks you compose under the hood of a scalable design: consistent hashing, bloom filters, sharding strategies, quorums, idempotency keys, leader election, and failure detection.
