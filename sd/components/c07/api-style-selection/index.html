API Style Selection

System map study sheet

What this sheet shows

How services expose and talk to each other: the REST vs gRPC vs GraphQL tradeoff, HTTP method idempotency, pagination strategies, versioning, sync vs async delivery, the real-time transport ladder (polling, long-polling, SSE, WebSockets), and the API gateway.

Trace the flow

  1. Client — REST, gRPC, GraphQL; then continue to API contract.
  2. API contract — auth + policy; then continue to Gateway / transport.
  3. Gateway / transport — sync or async; then continue to Service.
  4. Service — Observe the result, enforce the contract, and feed failures back into the design.
