Photo-Sharing Service system map

What this belongs to

An Instagram-style service where users upload photos, follow others, and browse a media-rich feed. The signature challenge is separating heavy binary media (blob storage + CDN) from lightweight metadata (a DB), processing uploads asynchronously into multiple sizes, and generating a feed over a media-heavy read-dominated workload.
