File Sync / Object Storage Service system map

System map study sheet

What this belongs to

A Dropbox/S3-style service that stores files durably and keeps them in sync across a user's devices. The signature challenge is transferring only the bytes that changed: split files into content-addressed chunks, dedup them globally, and separate a metadata service (file → chunk list, versions) from the raw blob store.
