Two thresholds, not one

Mechanism study sheet

What this sheet shows

One threshold turns every borderline item into an automated error. A band converts model uncertainty into the one resource that can resolve it — human judgement.

Show why a single cut-off is the wrong shape for this problem.

Trace the flow

  1. Calibrate the score — An uncalibrated 0.8 is not a probability, and thresholds mean nothing without calibration.
  2. Set the high cut-off — Above it, auto-remove without review.
  3. Set the low cut-off — Below it, auto-approve without review.
  4. Route the band — Between them, send to a human — where the model knows least.
  5. Tune per category — Child safety favours recall; spam favours precision.

What this belongs to

Screen user-generated content at platform scale using classifiers plus a human review queue. The signature challenge is that both error directions cause real harm, so the design is about routing uncertainty to humans rather than pushing a classifier toward perfect accuracy it will never reach.
